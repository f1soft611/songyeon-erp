# 메뉴 identity 시퀀스 복구 기록

- 날짜: 2026-10-01
- 변경 내용: 기존 메뉴 ID와 `tb_menu_menu_id_seq`를 비교해 다음 자동 생성 ID가 중복되지 않도록 시퀀스를 전진시킨다.
- 대상: `public.tb_menu`, `public.tb_menu_menu_id_seq`
- 영향: 메뉴 데이터와 스키마는 변경하지 않는다. 실행 중 메뉴 테이블 접근이 잠시 대기한다.
- 근거: 읽기 전용 조회에서 최대 ID 23, 시퀀스 `last_value=22` 및 ID 23 존재를 확인했다.
- 롤백: 시퀀스를 뒤로 되돌리는 것은 PK 충돌을 재발시킬 수 있어 금지한다. 롤백 SQL도 현재 데이터에 맞춰 재동기화한다.
- 적용 상태: SQL 준비 완료. 현재 DB 연결이 읽기 전용이므로 DB에는 미적용이다.
