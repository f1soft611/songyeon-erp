## 내용

- 요청: "테이블에 사용여부 컬럼 추가해주고 원재료마스터는 마지막사용일 뒤 부자재마스터는 쓰는제품 뒤에 사용여부 컬럼 추가해주고 조회조건도 포장유형처럼 추가해줘"
- 포장유형(`tb_box_type`) · 거래처(`clients`)와 같은 정의로 더했다.
  - `use_yn CHAR(1) NOT NULL DEFAULT 'Y'`
  - 검사 제약 `ck_materials_use_yn`: `use_yn IN ('Y', 'N')`
- 있는 원재료 · 부자재 53건은 기본값으로 모두 Y(사용)가 됐다.
- 값을 바꾸는 곳: 원재료마스터 · 부자재마스터 사용여부 체크박스 + 제목줄 [저장]
  - `MaterialMaster_SQL_postgresql.xml` `updateMaterialUseYn`
  - 바꾸면 수정자 · 수정일시(`upd_user_id` · `upd_dt`)도 남긴다.

## 영향 범위

- 원재료마스터 · 부자재마스터 목록이 `useYn` 을 돌려준다.
- 기본값이 있어서 `use_yn` 을 적지 않는 기존 INSERT(원재료 · 부자재 등록)는 그대로 Y 로 들어간다.
- 같은 날 이어서, 다른 화면의 원재료 · 부자재 고르기는 사용 중만 보이게 했다(제품BOM · 발주 · 입고 · 반품 · 레시피 · 원재료 대체 · 일괄적용). 재고 조회 · 수불대장 · 거래처별관리대장 조회 거름 · 코드 · 이름으로 찾는 곳은 전체 그대로다.
- 롤백하면 사용안함으로 바꾼 값도 사라진다. 서버 · 화면 코드도 20261023_009 이전으로 함께 돌려야 한다.
