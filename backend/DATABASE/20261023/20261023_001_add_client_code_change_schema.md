# 20261023_001 거래처코드(client_code) 추가 변경 이력

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-23 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 스키마 변경(컬럼 · 고유 인덱스 추가) + 데이터 채우기 |
| 대상 표 | `clients` |
| 적용 | 2026-10-23 적용 완료 (트랜잭션 시험 실행: 다시 적용해도 같음, 롤백하면 처음과 같음 확인 후 적용) |
| 롤백 | `20261023_001_rollback.sql` |

## 내용

- 요청: "거래처도 초기 000001 로 시작해서 자동발번하는거야"(계획 · 사양서 `docs/plan/20261023/20261023_001_거래처마스터_코드칸삭제_6자리자동번호_계획사양서.md`)
- `clients.client_code VARCHAR(6)` 를 더했다. 이름은 `clients` 표의 `client_` 규칙을 따랐다.
- 있는 거래처 19곳에 등록 순서(id)대로 000001 ~ 000019 를 매겼다.
- 고유 인덱스 `uq_clients_client_code` 를 걸었다. 코드가 있는 줄끼리만 겹치지 않으면 되고, 빈 코드는 막지 않는다.
- 이후 새 거래처는 서버가 코드를 매긴다(`PartnerMasterServiceImpl.nextClientCode`).
  - 6자리 숫자 코드 가운데 가장 큰 번호 + 1, 없으면 000001
  - [거래처 등록]과 엑셀 올리기의 새 거래처 모두 같다.

## 영향 범위

- 거래처마스터 목록 응답에 `clientCode` 가 더해진다. 화면은 코드를 보여 주지 않는다.
- 거래처를 이름으로 잇는 다른 화면(제품 · 원재료 · 수주 · 회계 등)은 바뀌지 않는다.
