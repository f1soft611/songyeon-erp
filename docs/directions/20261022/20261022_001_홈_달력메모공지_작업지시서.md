# 20261022_001 홈: 대시보드 → 홈, 메신저·AI 빼기, 달력 + 메모·공지 작업지시서

## 요청 (2026-10-22)

- (스크린샷) "지금 대시보드를 이렇게 바꿀 수 있나? 홈으로. 메신저AI는 빼고"
- 사용자 답
  - 왼쪽 모듈 타일 모양: 바꾸지 않는다. 이름(대시보드 → 홈) · 메신저·AI 빼기는 한다.
  - 상단 '처리할 것' 줄: 필요 없다.
  - 달력의 공지: 공용 메모 = 공지(송연 `dashboard_memos`)

## 완료 조건

1. 왼쪽 모듈 · 메뉴 이름 '대시보드'가 '홈'이다. 메신저·AI 모듈은 보이지 않는다.
2. 홈 본문: 왼쪽 달력(월 이동, 오늘 · 고른 날 표시, 공휴일, 날짜 칸에 메모·공지), 오른쪽 고른 날의 메모·공지 목록 + [메모·공지 추가]
3. 메모·공지는 저장된다(송연 원본 규칙): 공용 = 공지(모두에게 보임), 개인 = 나만. 개인 메모는 작성자(또는 관리자)만 고치고 지운다.
4. 메뉴 데이터 변경은 날짜별 SQL · 변경 이력 · 롤백(docs/database · backend/DATABASE 같이), 시험 실행 후 적용
5. 결과 문서 · 스크린샷: `docs/result/20261022/home-calendar-memo`

## 하지 않는 것

- 왼쪽 타일 모양, '처리할 것' · 건수 배지
- 메신저·AI 화면 코드 삭제(모듈만 사용안함으로 둔다 — 되돌리기 쉽게)
- 아이콘 변경(아이콘 목록에 집 모양이 없음)
