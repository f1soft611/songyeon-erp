## 완료 조건 · 사양

1. 제목줄에서 [삭제]를 뺀다.
2. 상태 칸: 체크박스(머리 전체 체크). 끄고 [저장] = `use_yn = 'N'`, 켜고 [저장] = 'Y'. 사용안함 줄도 고칠 수 있다.
   - 칸 이름은 지금처럼 '상태'(2026-10-20 사용자 지정)
   - 다시 켤 때 같은 이름의 사용 중 창고가 있으면 막는다("이미 등록된 창고입니다").
   - 기본창고(입고창고)를 끄면 막는다(지금 규칙: 입고창고 한 곳은 있어야 함).
3. 코드 칸을 없애고 엑셀 다운로드에서도 뺀다. 새로 등록하면 서버가 6자리 숫자로 매긴다.
   - 값: 표 전체 6자리 숫자 코드(`^[0-9]{6}$`)의 최댓값 + 1, 없으면 `000001`
   - 이미 있으면 다음 번호. 옛 'WH-…' 는 세지 않는다.
4. 오른쪽 클릭 [행 삭제] → [저장] = 물리 삭제(`DELETE FROM tb_warehouse`). 사용안함 줄도 보낸다.
   - 지금 검사는 그대로 둔다: 쓰는 곳이 있으면 막고, 기본창고는 막는다.
   - 창고 위치 · 하위 창고(FK)가 있으면 "창고 위치나 하위 창고가 있어 지울 수 없습니다"
5. 검색 칸: '창고 검색'(창고명만)
6. DB 구조 · 데이터 변경 없음. 기존 WH-… 줄 그대로
7. 결과: `docs/result/20261022/warehouse-like-box-type`
