## 지금 상태

- 제목줄: 조회 · 엑셀 다운로드 · 추가 · 저장 · 삭제. [삭제] = 고른 줄을 사용안함으로(논리삭제, `use_yn = 'N'`)
- 사용여부 칸: 글자('사용중' / '사용안함'), 고칠 수 없음. 사용안함 줄은 아무 칸도 고칠 수 없음
- 서버 저장(`POST /api/v1/co/master/box-type`): 사용 중인 줄만 고치고 사용여부는 바꾸지 않음

## 완료 조건

1. 제목줄에 [삭제]가 없다.
2. 사용여부 칸은 체크박스(머리 전체 체크 포함)이다. 공통코드 관리 '사용여부'와 같은 모양이다.
3. 체크를 끄고 [저장]하면 사용안함, 켜고 [저장]하면 다시 사용으로 저장된다. 사용안함 줄도 고칠 수 있다.
4. 다시 켤 때 같은 코드가 이미 사용 중이면 막는다.
5. 결과 문서 · 스크린샷: `docs/result/20261022/box-type-use-checkbox`
