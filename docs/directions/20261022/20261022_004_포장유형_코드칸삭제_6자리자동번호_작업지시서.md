## 지금 상태 (읽기 전용 확인)

- 화면 코드 칸: 새 줄은 'PACK-' 뒤를 적고, 비우면 서버가 'PACK-' + (가장 큰 PACK-숫자 + 1, 3자리)를 매긴다.
- `tb_box_type.box_type_cd`: 4줄 모두 'PACK-…'. 다른 표에서 가리키는 곳 없음(FK 0, 다른 표 · 매퍼에 칸 없음). 유니크 `(factory_code, plant_code, box_type_cd, apply_start_dt)`

## 완료 조건 · 사양

1. 화면에 코드 칸이 없다. 엑셀 다운로드에도 코드 칸이 없다.
2. 새로 등록하면 서버가 코드를 매긴다
   - 형식: 6자리 숫자(`000001`)
   - 값: 같은 사업장 · 사업부에서 6자리 숫자 코드(`^[0-9]{6}$`) 가운데 가장 큰 값 + 1(사용안함 줄 포함)
   - 6자리 숫자 코드가 없으면 `000001`
   - 이미 있는 코드면 다음 번호로 넘어간다. 화면에서 보낸 코드는 쓰지 않는다.
3. 기존 'PACK-…' 4줄은 그대로 둔다(숫자 코드가 아니라 번호 계산에 들지 않는다 → 다음 등록은 `000001`).
4. 수정은 코드를 바꾸지 않는다(지금과 같음).
5. 저장된 칸 순서는 코드 칸이 빠지면 처음 순서로 다시 시작한다(`resetGridStorageIfColumnsChanged`, storageKey 그대로).
6. DB 구조 · 데이터 변경 없음
