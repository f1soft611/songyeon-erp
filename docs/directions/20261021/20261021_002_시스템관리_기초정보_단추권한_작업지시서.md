# 20261021_002 시스템 관리 · 기초정보 화면 단추를 메뉴 권한에 맞추기 작업지시서

## 요청 (2026-10-21)

- "메뉴관리에서 기본기능 설정하면 권한에 따라서 버튼이 보이고 안 보이고 하나? 지금 다른 화면들은 저장 버튼 이런 거 다 화면 자체에서 만든 것 같아서"
- "그럼 지금 시스템관리 쪽 화면이랑 공통관리 > 기초정보 하위 화면들 먼저 그렇게 변경해줘"

## 사용자 결정

| 항목 | 결정 |
| --- | --- |
| 쓰기 권한이 없을 때 셀 편집 | 막는다 |
| 엑셀 단추 | 엑셀 권한만으로 보인다. [엑셀 올리기]는 엑셀 + 쓰기 |

## 대상 (11개 화면)

- 공통관리 > 기초정보: 공통코드 관리 · 포장유형 · 창고등록 · 제품마스터 · 거래처마스터 · 거래처별 제품조회 · 원재료마스터 · 부자재마스터
- 환경설정 > 시스템 관리: 모듈관리 · 권한관리 · 메뉴관리

## 완료 조건

1. 메뉴관리 기본기능 4칸(읽기 · 쓰기 · 삭제 · 엑셀)에 따라 위 화면의 제목줄 단추, 화면 안 단추, 그리드 오른쪽 클릭 [행 추가] · [행 삭제], 셀 편집이 보이거나 막힌다.
2. 권한이 모두 있는 사용자(시스템 관리자)의 화면은 지금과 같다(엑셀 단추 규칙만 엑셀 권한 기준).
3. 결과 문서와 스크린샷을 `docs/result/20261021/master-button-permission` 에 남긴다.

## 하지 않는 것

- 서버 API 의 메뉴 권한 검사(지금도 없음, S_ERP 와 같음)
- F1-Grid 수정
- 다른 메뉴 화면(인사 · 회계 · 레시피 등)은 다음 작업
