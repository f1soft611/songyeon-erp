# 20261021_004 인사관리: 로그인계정관리 탭 삭제 · 사원 등록 때 계정 함께 만들기 작업지시서

## 요청 (2026-10-21)

- "인사회계의 로그인계정관리라는 탭을 없애고 사원관리에서 신규사원등록할 때 초기비번 설정해줘"
- "username 컬럼도 name 컬럼이랑 동일한 값으로 채워주고"

## 완료 조건

1. 인사관리에 '로그인계정관리' 탭이 없다(사원관리 · 근태관리 · 증명서신청).
2. 사원관리 [사원 등록]으로 등록하면 바로 로그인 계정이 생긴다.
   - `employees.username` = 이름, 비밀번호 = `changeme`
   - 계정 표 `tb_login_account`(`login_code` = 사번) 한 줄 + 일반 사용자(DEFAULT_USER) 역할
   - 로그인: 사번 + changeme
3. 같은 이름의 사원(= 같은 username)이 이미 있으면 등록을 막고 알려 준다(username 은 UNIQUE, 메뉴 권한 · 내 정보가 username 으로 사람을 찾는다).
4. 등록 창에 첫 로그인 안내(사번 · changeme)가 있다.
5. 결과 문서 · 스크린샷: `docs/result/20261021/hr-account-on-register`

## 하지 않는 것

- 이름을 고칠 때 username 바꾸기(문서함 · 공지 등 username 으로 남긴 기록과 이어지지 않게 됨)
- 기존 사원 데이터 변경(지금 2명 모두 username = 이름, 계정 있음)
- 서버의 계정 저장 · 거두기 API 삭제(화면에서만 뺀다)
