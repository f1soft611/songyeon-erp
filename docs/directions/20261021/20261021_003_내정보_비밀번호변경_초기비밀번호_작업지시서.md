# 20261021_003 내 정보 비밀번호 변경 · 첫 비밀번호 changeme 작업지시서

## 요청 (2026-10-21)

- "dashboard/profile 여기서 비밀번호 변경 가능하게 만들어주고"
- "최초로 아이디 생성하면 로그인 가능한 비밀번호는 changeme 로 만들어줘"

## 지금 상태

- 비밀번호 변경은 프로필 메뉴 [보안 설정](`/dashboard/security`, S_ERP 와 같은 화면)에만 있다. 내 정보(`/dashboard/profile`)에는 없다.
- 인사관리 [아이디 만들기]는 비밀번호를 꼭 적어야 만들어진다("처음 만들 때는 비밀번호도 정해주세요").

## 완료 조건

1. 내 정보 화면에 '비밀번호 변경'(현재 · 변경 · 확인)이 있고, 바꾸면 그 비밀번호로 로그인된다.
2. 인사관리에서 아이디를 처음 만들면 비밀번호는 `changeme` 이다. 창에는 비밀번호 칸 대신 그 안내가 나온다.
3. 이미 계정이 있는 사원은 지금처럼 비밀번호를 바꿀 때만 적는다.
4. 결과 문서와 스크린샷을 `docs/result/20261021/profile-password` 에 남긴다.

## 하지 않는 것

- 첫 로그인 때 비밀번호 변경 강제
- [보안 설정] 화면 변경(그대로 둔다)
