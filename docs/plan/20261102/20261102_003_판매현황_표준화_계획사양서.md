# 20261102_003 판매현황 표준화 계획 · 사양서

- 요청
  - "판매현황도 표준맞춰주고"
  - "거래처코드/명조회 가능"
  - "상세조건에서 품목코드/명 조회가능"
  - "삭제 막는 조건 있으면 마우스클릭 행삭제랑 delete키 삭제도 막기"
- 화면: 판매관리 > 판매조회 > 판매현황(`INSalesStatusView`)
- 같은 방식: 판매등록(`20261102_002`), 출하등록(`restoreBlockedGridDeletes`)

## 바꿀 것

- 구조: 화면(`SalesStatusManagementPage`) · 조회/삭제(`hooks/useSalesStatusManagement`) · 그리드(`components/SalesStatusGrid`)로 나눈다.
- 검색칸: 거래처코드/거래처명. 상세 조회(⌄): 판매일자 기간(필수, 이번 달 1일~오늘) · 품목코드/명.
- 서버: `selectRecords` · `selectReceipts` 의 거래처 · 품목 조건에 코드를 더한다. 토탈집계도 같은 쿼리라 같이 코드로 찾아진다. API 와 DB 는 그대로다.
- 그리드 첫 칸은 `No` 로 한다.

## 삭제 막기

- 원본 `sales_delete` 와 지금 서버에는 줄별 삭제 제한이 없다. 막는 조건은 삭제 권한뿐이다.
- 권한이 없으면 [삭제] 단추와 오른쪽 클릭 [행 삭제]가 없고, Delete 키로 뺀 줄은 `restoreBlockedGridDeletes` 로 되살리고 알린다.

## 검증 기준

- 타입 검사 · 빌드, 판매 테스트 통과
- 권한 있음 · 없음에서 Delete 키 동작을 화면 테스트로 확인
