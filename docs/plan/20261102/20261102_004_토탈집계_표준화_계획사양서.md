- 같은 방식: 판매현황(`20261102_003`)

## 바꿀 것

- 구조: 화면(`SalesTotalManagementPage`) · 조회(`hooks/useSalesTotalManagement`) · 그리드(`components/SalesTotalGrid`)로 나눈다.
- 검색칸: 거래처코드/거래처명. 상세 조회(⌄): 품목코드/명 · 일자 기간(필수, 이번 달 1일~오늘) · 구분(입고 · 출고).
- 구분은 받은 목록을 화면에서 거른다. 합계 · 엑셀도 거른 줄만 쓴다.
- 그리드: 첫 칸은 `No`, 숫자 칸은 판매현황처럼 `currency`, 구분 칸은 `direction` 으로 바꾸고 저장된 칸 순서를 다시 시작한다.
- 합계 타일 · 맨 밑 합계 줄 · 단가 없는 줄 경고는 관리부 요구라 그대로 둔다.
- 기본 기간 · 조회 조건 변환은 판매현황과 같이 쓴다(`utils/salesStatus`).

서버 · DB 는 바꾸지 않는다.
