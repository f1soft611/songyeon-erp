## 원본 규칙

- **이미 쓴 판은 고치지 않는다**: 지금 판으로 쓴 점검표가 한 장이라도 있으면 질문 · 묶음 · 보기를 고치는 순간 판을 통째로 베껴 새 판(`N판`, 메모 `점검표 N장을 쓴 뒤 고침`)을 뜨고 거기를 고친다. 지난 점검표는 그때 질문 · 보기 그대로 열린다. 화면이 들고 있던 옛 판의 줄 번호는 **같은 자리(sort_order)** 의 새 판 줄로 다시 찾는다
- 제목 · 분류 · 대상 · 기간은 판이 아니라 양식에 저장(새 판 안 뜸). **대상은 쓴 장이 생기면 못 바꾼다**(`이미 쓴 점검표가 있어 '대상' 은 바꿀 수 없습니다. 새 서류로 만들어주세요.`), 기간은 언제든
- 서류 이름은 겹칠 수 없다(`'{이름}' 은(는) 이미 있는 서류입니다`), 비면 `서류 제목을 적어주세요`, 기간은 7가지 중(`기간을 '매일 / 주1회 / … / 수시' 중에서 골라주세요`)
- 새 서류: 1판(메모 `새로 만듦`) + 기본 보기(적합 O 2 · 미흡 △ 1 · 부적합 X 0 · 해당없음 N/A 2, 세부내역 · 부적합내역 칸). `질문 가져오기` 를 고르면 그 서류의 지금 판 보기와 줄(묶음 관계 포함)을 통째로 베낀다
- 지우기 없음. **목록에서 내리기 / 다시 올리기**만(쓴 점검표는 남고 새로 쓸 수만 없다)
- 보기 저장: 하나 이상, 이름이 같은 보기 둘 안 됨(`'{이름}' 이(가) 두 번 있습니다. 고를 답은 서로 달라야 합니다.`), 점수는 숫자나 빈칸(`'{이름}' 의 점수는 숫자로 적어주세요`), 이름이 빈 줄은 버린다
- 줄 넣기: 질문(관리항목 · 필수 여부 · 본문) 또는 묶음(이름). 고른 줄 바로 밑에 끼운다(뒤 줄 자리 +1), 안 고르면 맨 끝. 고른 줄이 묶음이면 그 안으로, 질문이면 그 형제로. 본문이 비면 `묶음 이름을 적어주세요` / `질문을 적어주세요`
- 줄 고치기: 본문 · 관리항목 · 필수 여부(본문이 비면 `내용을 적어주세요`). 지우기: 묶음이면 안의 줄까지. 옮기기: 같은 묶음 형제끼리만 위 · 아래, 묶음은 딸린 줄을 데리고 통째로
- 없는 서류 `그런 서류가 없습니다`, 없는 줄 `그런 줄이 없습니다`

## API(`/api/v1/qm/haccp/prerequisite`)

| API | 내용 |
| --- | --- |
| `GET /forms` | 양식 목록(살아 있는 것 먼저): 질문 · 묶음 수, 만점, 대상, 기간, 쓴 장 수, 내려둠 |
| `POST /forms` | 새 서류 `{name, category, bindType, cycle, copyFrom}` → `{id, copied}` |
| `GET /forms/{id}` | 양식 한 벌(보기 · 줄 · 지금 판 · 그 판으로 쓴 장 수 `used`) |
| `PUT /forms/{id}` | 제목 · 분류 · 대상 · 기간 |
| `PUT /forms/{id}/active` | 내리기 · 다시 올리기 `{active}` |
| `PUT /forms/{id}/choices` | 보기 · 칸 `{choices, hasNote, hasDefect}` |
| `POST /forms/{id}/items` | 줄 넣기 `{rowKind, label, topic, required, afterId}` → `{id}` |
| `PUT /items/{id}` · `DELETE /items/{id}` · `PUT /items/{id}/move` | 줄 고치기 · 지우기 · 옮기기 `{dir: up/down}` |

- 만든 사람 · 새 판 뜬 사람 = 로그인 사번
- 권한: 원본은 양식 권한(`qdoc-form`)이 따로다. ERP 는 메뉴 권한으로 — 등록 · 수정 권한이 없으면 양식 만들기 탭을 보이지 않는다

## 화면(양식 만들기 탭)

- 왼쪽: [+ 새 서류 만들기] + 서류 카드(`이름`, `질문 N개 · 만점 N점 · 거래처마다/날짜마다 기간 · 쓴 것 N장 · 내려둠`). 살아 있는 것 먼저, 내려둔 것은 흐리게. 누르면 오른쪽 편집
- 새 서류 창: [만들기] 가 눌린다. 제목이 비면 `서류 제목을 적어주세요`, 서버 오류도 창 안에. 만들면 `만들었습니다`(`질문 N줄 가져옴`) 후 그 서류 편집
- 서류 블록: 제목 · 분류 · 대상(쓴 장이 있으면 잠김) · 기간, [목록에서 내리기 / 다시 올리기](내릴 때 확인 `이 서류를 목록에서 내립니다. 쓴 점검표는 그대로 남고, 새로 쓸 수만 없게 됩니다. 내릴까요?`) · [저장], 판 안내
- 질문 작성: 줄을 누르면 골라지고 다시 누르면 풀린다. [+ 묶음] · [+ 질문] 은 고른 줄 바로 밑(안 고르면 맨 끝)에 칸을 연다. 칸: 관리항목(새로 넣을 때 바로 전 관리항목을 물려받음) · 필수 여부 · 본문, Enter 저장(새로 넣으면 바로 밑에 다음 칸) · Shift+Enter 줄바꿈 · Esc 닫기, [저장] · [끝]/[취소]. 줄마다 [↑] [↓] [고치기] [지우기](지울 때 확인, 묶음이면 `이 묶음 안의 질문 N개도 같이 지워집니다`)
- 답변 작성: 보기 · 기호 · 점수 줄 고치기 · [지우기] · [+ 보기 추가], 세부내역 칸 · 부적합내역 칸, [답변 저장]
- 쓴 장이 있는 판을 고칠 때는 먼저 묻는다(`이 판으로 쓴 점검표가 N장 있습니다. … 새 판이 뜨고, 지난 점검표는 그때 질문 그대로 남습니다. …`)
- 저장할 때마다 서류 목록 · 점검 탭의 쓸 서류 목록을 다시 읽는다
