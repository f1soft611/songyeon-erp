## 1. 지금

- 입고 등록 창(`ReceivingDialog`)의 거래처 · 품목은 글자를 쳐서 고르는 자동완성 칸이다.
- 거래처는 목록에 없는 이름도 그대로 들어간다(`freeSolo`). 품목은 [목록에 추가] 때 원재료명이 정확히 같아야 한다.

## 2. 바꾸는 것 (발주등록과 같게)

- 거래처 · 품목 칸: 읽기 전용 칸 + 칸 안 🔍(`거래처 선택` · `품목 선택`). 누르면 팝업(`MasterPickerDialog`)에서 코드 · 이름으로 찾아 고른다. 칸에는 `코드 · 이름`.
  - 거래처 후보: 지금과 같은 매입 거래처(`fetchVendors`, 코드가 있는 것).
  - 품목 후보: 지금과 같은 원재료(`fetchMaterialOptions`), 팝업 제목 `원재료`.
- [목록에 추가]: 고른 거래처 이름 · 고른 원재료(코드 · 이름)로 줄을 만든다. 거래처를 안 골랐으면 `거래처를 먼저 선택해주세요`, 품목 · 수량이 없으면 `품목과 수량을 입력해주세요`. 추가하면 품목 · 수량만 비우고 거래처는 남긴다(지금과 같음).
- 창을 열 때 거래처 · 품목을 비운다(지금과 같음).
- 그대로: 발주내역에서 가져오기(발주건 거래처 그대로), 단가 · 합계 계산, 확정 · 저장, 안내 문구 뜻(거래처 칸 설명의 '입력'은 '선택'으로).
- 고치는 파일: `pages/pu/inbound/receiving-register/components/ReceivingDialog.tsx` 만. `PickerField` 는 발주등록 창 것과 같은 모양을 이 파일에 둔다(다른 작업 중인 발주 파일은 건드리지 않는다).
