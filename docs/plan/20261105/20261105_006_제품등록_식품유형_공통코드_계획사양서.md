- 근거: 원본 `songyeon-app/templates/screens/product.html:16-21` — 제품등록의 포장유형과 보관방법 사이에 식품유형, 목록에서만 고른다(손으로 치면 오타가 새 유형이 된다). 비워 둘 수 있다(`app.py resolve_food_type`).

## 지금

- `products.food_type`(text)는 이름 글자다. 라벨등록이 라벨 버전을 '사용중'으로 정하면 라벨의 식품유형 글자(자유 입력)를 그대로 베낀다(`copyVersionToProducts`).
- 제품 7건 중 1건만 값이 있다: `조미식품`. 공통코드 이름과 같지 않다.
- 라벨 버전(`product_label_versions.food_type`)도 1건(`조미식품`)이다. 라벨 글자는 인쇄용이라 이번에 바꾸지 않는다.
- 제품등록 화면 · 제품등록 API 에는 식품유형이 없다.
- 제품을 읽는 곳: 라벨 예전 방식 조회(`LabelDAO.selectProductLabel`)만 이 값을 보여준다(라벨 출력의 버전 없는 제품).
