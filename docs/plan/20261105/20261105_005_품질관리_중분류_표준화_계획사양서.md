## 3. 화면 표준 (판매 · 구매 표준화와 같음)

- 화면 · 훅 · 표 컴포넌트로 나눈다. 표 첫 칸 `No`. 검색줄 + 상세 조회(⌄), 조회 뒤 `조회 결과 총 N건입니다.`(SearchResultMessage). 상세 조회는 빈 값으로 시작한다.
- 라벨등록: 검색줄 제품명/제품코드(서버 조회), 상세 조회 라벨 상태(등록된 것 · 안된 것). 제목줄 [조회] · [회사 고정정보 설정]. 줄의 [라벨등록] 단추 그대로.
- 표시사항 요청: 검색줄 업체명/레시피명(화면에서 거름), 상세 조회 상태(아직 안 끝난 것 · 끝난 것). 제목줄 [조회]. 줄의 [표시사항] · [제품으로 옮기기] 그대로.
  - 예전에는 '아직 안 끝난 것'으로 시작했고 탭 옆에 남은 요청 수를 보였다. 상세 조회는 빈 값으로 시작(전체)하는 표준이라 그대로 따르고, 조회 결과 안내로 건수를 본다.
- 라벨양식: 검색줄 양식 이름(화면에서 거름). 제목줄 [조회] · [새 양식] · [항목 등록] · [마크 등록]. 줄의 [편집] · [복사] · [삭제](쓰는 제품이 있으면 막음) 그대로.
- 세 표 모두 줄 추가 · 삭제 기능이 없다: 오른쪽 클릭 [행 추가] · [행 삭제]가 없고, Delete 키로 줄이 빠지지 않게 막는다.
- 실시간 온도: 표가 아닌 센서 카드 화면이라 검색 · 표 표준은 해당 없음. 폴더 · 주소만 옮기고 본문 여백을 다른 화면과 같게(p 1).
