# 20261023_022 거래처 콤보박스(이름 표시 · 코드 저장) 계획 · 사양서

- 요청
  - "제품등록할때 거래처 콤보박스에서 선택하면 코드값이 물리게 할 순 없어? 꼭 변환작업을 해야해?"
  - "견적도 코드값으로 변환할게"
- 사용자 결정
  - 범위: 제품등록 · 제품마스터 · 견적
  - DB 는 사용자가 직접 바꿨다(`quotes.client_name` → `client_code`, `quotes.storage` 이름 → 코드). 저는 확인 · 기록만 한다.

## DB 확인(개수만)

- `quotes`: `client_code`(6번째, text) 1건이 거래처마스터에 있다. `storage` 는 `003`(공통코드 STORAGE_METHOD 에 있다).
- `products`: `client_code` 6건 모두 거래처마스터에 있다. `storage` 001 3 · 002 1 · 003 2
- `quotes` 맨 끝 `product_code`(text, 비어 있음): 서버가 쓰지 않는다. 손대지 않는다.

## 서버

| 대상 | 내용 |
| --- | --- |
| `GET /api/v1/co/master/item-master/client-options` (새로) | 사용 중 거래처 `{clientCode, name}`, 이름순 |
| `ItemMasterService.resolveClientCode(raw, current)` (새로) | 비우면 null, 지금 값과 같으면 그대로(사용안함이 돼도 둔다), 아니면 사용 중 거래처코드만 받는다 |
| 제품마스터 창 저장 `PUT .../info` | `clientCode` 를 받아 그대로 저장(이름 변환 없음) |
| 제품등록 `POST /api/v1/sa/products` | `clientCode` 를 받아 그대로 저장 |
| 견적 조회 | `clientCode` + 거래처 이름(`clientName`), `storage`(코드) + `storageNm` |
| 견적 저장(새로 · 고침) | `clientCode` 그대로 저장(검사는 위와 같음), 보관방법은 공통코드 코드만 |
| 레시피 → 견적(`EgovRecipeShare.insertQuote`) | 레시피에는 거래처가 이름뿐이라 여기만 이름으로 코드를 찾는다(없으면 비움) |

## 화면

| 화면 | 내용 |
| --- | --- |
| 제품등록 | 거래처: 사용 중 거래처 목록에서 고르기(이름 표시, 값은 코드, 자유 입력 없음). 견적에서 오면 견적의 코드 · 보관방법 코드를 그대로 채운다 |
| 제품마스터 창 | 거래처 칸을 같은 고르기로. 저장은 코드 |
| 견적 창 | 거래처를 같은 고르기로, 보관방법은 공통코드 코드로 고르기 |
| 견적 목록 · 인쇄 | 서버가 붙여 준 거래처 이름 그대로 |
