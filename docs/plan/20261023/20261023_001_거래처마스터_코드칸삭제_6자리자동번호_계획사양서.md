# 20261023_001 거래처마스터 코드 칸 삭제 · 6자리 자동번호 계획 · 사양서

- 요청
  - "거래처 마스터 화면도 코드컬럼 없애주고"
  - "거래처도 초기 000001 로 시작해서 자동발번하는거야"
- 화면: 기준정보 > 기초정보 > 거래처마스터(`BSPartnerMasterView`)
- 같은 방식: 포장유형(결과 `docs/result/20261022/box-type-auto-code`)

## 지금 상태

- 거래처 표 `clients` 에는 코드 컬럼이 없다.
- 화면은 'C-' + 표 번호(예: C-007)를 보기 전용 코드로 만들어 보여 준다(2026-10-20).
- 이 코드는 그리드 칸, 엑셀 다운로드 첫 칸, 조회어 검색에 쓰인다.

## 바꿀 것

### 화면(프론트)

- 그리드의 코드 칸을 뺀다.
  - 칸 순서 저장값은 `GRID_FIELDS` 가 바뀌면 처음 순서로 다시 시작한다(`resetGridStorageIfColumnsChanged`).
- 엑셀 다운로드는 그리드와 같은 차례(거래처명 · 분류 · 사업자등록번호)로 하고 코드 칸을 뺀다.
- 조회어는 거래처명으로만 찾는다. 안내 문구는 '거래처명 검색' 이다.
- 보기 전용 코드 함수 `clientCodeOf` 를 없앤다.

### DB `20261023_001`

- `clients.client_code VARCHAR(6)` 를 더한다.
  - 이름은 `clients` 표의 `client_` 규칙을 따른다(S_ERP 거래처 표 `tb_customer_info` 는 `customer_code`).
- 있는 거래처는 등록 순서(id)대로 000001 부터 번호를 준다.
- 고유 인덱스 `uq_clients_client_code` 를 건다. 코드가 빈 줄은 겹쳐도 된다(기존 프로그램이 코드 없이 넣는 경우).

### 서버

- 거래처를 새로 넣을 때 서버가 코드를 매긴다.
  - 넣는 경로: [거래처 등록], 엑셀 올리기의 새 거래처
  - 규칙: 표에 있는 6자리 숫자 코드 가운데 가장 큰 번호 + 1, 없으면 000001(포장유형과 같음)
  - 이미 있는 코드면 다음 번호로 넘어간다.
- 화면에서는 코드를 받지 않는다.
- 수정, 엑셀로 있는 거래처 덮어쓰기는 코드를 바꾸지 않는다.
- 목록 응답에는 `clientCode` 를 담는다(화면은 보여 주지 않는다).

## 검증

- 프론트 `tests/partner-master.test.ts` 를 고친다.
  - 코드 검색이 안 된다.
  - 엑셀 칸 3개다.
- 백엔드 `PartnerMasterServiceImplTest` 에 테스트를 더한다.
  - 등록 · 엑셀 새 거래처에 000001, 가장 큰 번호 + 1, 겹치면 건너뜀
- DB 스크립트를 시험 실행한다(적용 → 다시 적용 → 롤백 → ROLLBACK).
- 화면을 캡처한다(거래처 목록은 예시 값으로 바꿔 찍는다).
- 결과: `docs/result/20261023/partner-master-no-code/`
