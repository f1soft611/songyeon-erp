# 20261023_026 수주등록 제목줄 [저장] · 사용여부 계획 · 사양서

- 요청: "수주등록에 저장버튼도 있어야될거같고 동일하게 사용여부 컬럼 있어야될거같아 마지막에 저장,삭제 버튼 있는 컬럼은 없애고"
- 사용자 결정
  - 사용안함 수주는 생산확정 · 출하등록의 수주 가져오기에서 뺀다.
  - 삭제는 없앤다(지우지 않고 사용여부로 내려놓는다). 저장 전 새 줄만 우클릭 [행 삭제]로 뺄 수 있다.
  - 조회조건에 사용여부(전체 · 사용중 · 사용안함, 기본 사용중)를 넣는다.

## DB

- `20261023_016`: `sales_order.use_yn CHAR(1) NOT NULL DEFAULT 'Y'` + 검사 제약(Y/N). 있는 수주는 모두 Y.

## 화면(`SalesOrderPage.tsx`)

- 마지막 칸([저장] · [수정] · [삭제])을 없앤다.
- 저장된 줄도 바로 고친다([수정] 으로 풀던 잠금을 없앤다). 생산확정 · 출하등록에서 가져간 줄은 지금처럼 고치지 못한다.
- 가져간 줄 표시('생산확정에서 가져감' 등)는 보기 전용 칸 '가져감' 으로 남긴다.
- 사용여부 체크박스 칸(물류출고일 뒤). 가져간 줄은 바꾸지 못한다.
- 제목줄 [저장]: 새 줄(빈 줄은 건너뜀)은 등록, 고친 줄은 수정. 첫 오류에서 멈추고 그 칸으로 보낸다. 다 되면 다시 조회한다. 바뀐 것이 없으면 꺼져 있다.
- 우클릭 [행 삭제]: 우클릭한 줄이 저장 전 새 줄일 때만 켠다.
- 조회조건: 수주일 옆에 사용여부 토글(기본 사용중). 바꾸면 다시 조회한다. 저장하지 않은 변경이 있으면 [조회] · 토글 · 날짜 조회 전에 묻는다.
