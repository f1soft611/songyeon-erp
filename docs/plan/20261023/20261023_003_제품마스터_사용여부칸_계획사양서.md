# 20261023_003 제품마스터 사용여부 칸 계획 · 사양서

- 요청: "제품마스터 화면에서 작업컬럼에 사용안함을 빼고 사용여부 컬럼을 따로 만들어줘 포장유형이랑 창고등록처럼"
- 화면: 기준정보 > 기초정보 > 제품마스터(`BSItemMasterView`, `ItemMasterPanel`)
- 같은 방식: 창고등록(`WarehousePanel`) · 포장유형(`BoxTypePanel`)의 사용여부 체크박스 칸 + 제목줄 [저장]

## 지금

- 작업 칸 단추: 상세보기 · 수정 · 변경로그 · 사용안함(되돌리기). 누르면 확인 창이 뜨고, 바로 서버에 반영된다.
- 사용안함 제품은 품목명 옆에 '사용안함' 칩으로 보인다.
- 서버: `PUT /api/v1/.../products/{code}/discontinue {discontinued}`(그대로 쓴다)

## 바꿀 것(프론트만)

- 작업 칸에서 사용안함 · 되돌리기 단추를 뺀다(상세보기 · 수정 · 변경로그는 그대로).
  - 칸 너비는 300 에서 230 으로 줄인다.
- 사용여부 칸(`useYn`)을 더한다.
  - 체크박스이고 머리줄에도 체크박스가 있다. 체크하면 사용(Y), 끄면 사용안함(N)이다.
  - 다른 칸은 고칠 수 없다.
  - 쓰기 권한이 없으면 체크박스를 바꿀 수 없다(`readOnlyColumns`).
- 품목명 옆 '사용안함' 칩은 사용여부 칸과 겹쳐서 뺀다.
- 제목줄에 [저장]을 더한다(쓰기 권한).
  - 바뀐 줄만 사용여부를 서버에 보낸다(`setProductDiscontinued`).
  - 다 보내면 다시 불러오고 '저장되었습니다' 를 띄운다.
  - 저장하지 않은 변경이 있으면 [조회] 때 버릴지 묻는다(창고등록과 같음).
- '사용안함도 보기' 체크는 그대로 둔다(끄면 사용 중인 제품만 불러온다).
- 칸 순서 저장값: `GRID_FIELDS` 로 칸이 바뀐 것을 알아 처음 순서로 다시 시작한다(`resetGridStorageIfColumnsChanged`).
- 바뀐 줄을 고르는 규칙은 `item-master/utils/itemMaster.ts` 로 뺀다.
