# 20261023_006 거래처 분류 공통코드 · 사용 중 거래처만 고르기 · 칸 너비 계획 · 사양서

## 요청

1. "거래처명 컬럼이 너무 길어 하단 좌우 스크롤 안 생기게 만들어주고"
2. "당연히 사용중인 거래처만 선택가능해야지"
3. "공통코드에 CUSTOMER_CATEGORY 로 거래처 분류 만든거 있는데 지금 화면의 분류를 다 코드값으로 바꿔줘 팝업이랑 조회할때랑 공통코드랑 조인해서 명으로 보일 수 있게 테이블에 저장은 코드로"

## 1. 칸 너비(거래처마스터 그리드)

- 거래처명만 남는 너비를 다 가져가서(`flex 1.4`) 넓은 화면에서 길어 보였다.
- 바꾼다: 칸마다 비율을 나눈다.
  - 거래처명: `flex 2`, 최소 200
  - 분류: `flex 1`, 최소 130
  - 사업자등록번호: `flex 1`, 최소 140
  - 사용여부: 100 고정
- 화면 폭에 맞춰 늘고 줄어서, 최소 너비 합(순번 포함 약 630px)보다 넓은 화면에서는 좌우 스크롤이 생기지 않는다.

## 2. 사용 중 거래처만 고르기(고르는 목록만)

- 규칙
  - 고르는 목록(자동완성 · 선택지)에는 `use_yn = 'Y'` 인 거래처만 보인다.
  - 이미 저장된 자료의 거래처 이름, 저장할 때 이름이 등록돼 있는지 보는 검사, 사업자번호 찾기는 사용안함 거래처도 그대로 찾는다. 그래야 예전 자료를 다시 저장할 때 막히지 않는다.
  - 조회(보고서) 거름 목록인 거래처별관리대장은 전체를 둔다(사용안함 거래처의 지난 자료도 봐야 한다).

| 쿼리 | 쓰는 곳 | 바꿈 |
| --- | --- | --- |
| `ItemMaster.selectClientNames` | 제품 창 업체 고르기, 생산확정 거래처 칸 | 사용 중만 |
| `MaterialMaster.selectVendorClients` | 원재료 · 부자재 납품업체, 발주 창, 수불대장 발주 창 | 사용 중만 + 매입 분류 |
| `SalesOrder.selectSalesClientNames` | 수주등록 거래처 | 사용 중만 + 매출 분류 |
| `AccSales.selectVendorClientNames` | 매출 · 매입관리 매입 입력 | 사용 중만 + 매입 분류 |
| `AccSales.selectActiveClientNames`(새로 만듦) | 매출 · 매입관리 매출 입력 | 사용 중만 |
| `AccSales.selectSalesClientNames` | 거래처별관리대장 조회 거름 | 그대로(전체) |

## 3. 분류를 공통코드로

- 공통코드 `CUSTOMER_CATEGORY`(SONGYEON 회사)
  - 001 = 매입거래처
  - 002 = 매출거래처
  - 003 = 매입+매출 거래처
- DB `20261023_003`: `clients.client_type` 값을 바꾼다.
  - 매입 → 001(13건), 매출 → 002(5건), 매입+매출 → 003(1건)
  - 롤백은 되돌린다.
- 거래처마스터
  - 목록 · 한 곳 조회: 공통코드와 이어 `clientTypeNm`(이름)을 같이 준다.
  - 그리드 · 엑셀 다운로드는 이름을 보여 준다.
  - 등록 · 수정 창의 분류 고르기, 조회 조건 분류: 공통코드 사용 중 항목으로 만든다(`GET .../partner-master/client-types`). 저장은 코드다.
  - 서버 검사: 분류는 공통코드에 있는 사용 중 코드여야 한다.
- 엑셀
  - 양식 내려받기의 분류 칸은 이름으로 쓴다.
  - 올리기는 코드 · 이름 · 예전 글자(매입 · 매출 · 매입+매출)를 모두 받아 코드로 바꾼다. 공백과 '거래처' 를 빼고 견준다.
  - 제품BOM 에만 있는 이름은 '매출' 에 맞는 코드로 채운다.
- 다른 화면
  - 예전 `client_type LIKE '%매입%'` · `'%매출%'` 는 공통코드 이름으로 거른다. 코드 번호를 코드에 박지 않는다.
  - 수주 저장 검사(`selectClientType`)는 이름을 돌려줘서 '매출' 이 들어 있는지 그대로 본다.
- 같은 묶음 코드가 다른 회사에도 생기면 겹칠 수 있다. 그래서 조인은 SONGYEON 회사의 묶음으로만 한다.
