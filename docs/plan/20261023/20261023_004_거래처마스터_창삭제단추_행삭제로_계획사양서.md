- 요청: "창 안에 삭제버튼 없애주고"
  - 앞선 제안: 삭제는 오른쪽 클릭 [행 삭제]로 한 군데에 모은다(포장유형 · 창고와 같음).
- 화면: 기준정보 > 기초정보 > 거래처마스터(`PartnerMasterPanel`, `PartnerMasterDialog`)

## 지금

- 줄을 누르면 거래처 창이 열린다.
- 창 왼쪽 아래 [삭제] → 확인 창 → 바로 `DELETE /api/v1/co/master/partner-master/{id}`

## 바꿀 것(프론트만)

- 창: [삭제] 단추와 `onDelete` 를 없앤다. 창에서는 등록 · 수정만 한다.
- 그리드
  - 오른쪽 클릭 [행 삭제]로 줄을 지움 표시한다. 삭제 권한이 있을 때만 메뉴가 보인다.
  - 제목줄 [저장]으로 지운 줄을 서버에서 지운다(실제 삭제, 기존 API 그대로).
  - 칸은 모두 고칠 수 없다(`editable: false`). 줄을 누르면 창이 열리는 것은 그대로다.
- 제목줄
  - [저장]: 쓰기 또는 삭제 권한이 있을 때 보인다. 바뀐 것이 있을 때만 켜진다.
  - 저장하지 않은 변경이 있으면 [조회] 때 버릴지 묻는다.
- 사용여부 체크박스는 다음 작업이다(DB `clients.use_yn` 은 `20261023_002` 로 만들어 두었다).
