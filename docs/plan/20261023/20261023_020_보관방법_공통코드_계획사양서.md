# 20261023_020 보관방법 공통코드(STORAGE_METHOD) 계획 · 사양서

- 요청: "제품등록 화면에서 보관방법을 공통코드 STORAGE_METHOD 로 적용시켜줘"
- 사용자 결정: 제품 표에는 **코드로 저장**(거래처 분류 · 단위와 같이), 화면은 이름으로 보인다.
- 공통코드(SONGYEON, 사용자가 만든 것): 001 실온(1℃~35℃) · 002 냉장(0℃~10℃) · 003 냉동(-18℃이하)

## 지금

- `products.storage`(text)는 이름 글자다. 6건 모두 공통코드 이름과 같다(실온 3 · 냉장 1 · 냉동 2).
- 제품등록 · 견적 화면 선택지는 화면에 적힌 글자('냉장보관(0℃~10℃)' 등)다.
- 제품마스터 창은 자유 입력이다.
- 라벨: 라벨 버전을 확정하면 라벨의 보관방법 글자(자유 입력)를 `products.storage` 로 베낀다(`copyVersionToProducts`).
  - 라벨 출력의 예전 방식(`selectProductLabel`)은 `products.storage` 를 읽는다.

## 바꿀 것

| 구분 | 위치 | 내용 |
| --- | --- | --- |
| DB | `20261023_012` | `products.storage` 이름 → 코드(공통코드 이름과 같은 것만). 롤백용 백업 표 |
| 서버 | `ItemMaster_SQL_postgresql.xml` | 목록에 `storage_nm`, `selectStorageCodes` |
| 서버 | `ItemMasterServiceImpl` | `resolveStorageCode`: 비우면 없음, 사용 중 코드만 받는다. 제품마스터 창 저장이 쓴다 |
| 서버 | `ProductRegisterServiceImpl` | 제품등록도 같은 검사 |
| 서버 | `PartnerItem_SQL_postgresql.xml` | 목록에 `storage_nm` |
| 서버 | 출하확정 · 출하현황 · 라벨(`selectProductLabel`) | `storage` 를 이름으로 돌려준다(보기 · 인쇄용, 화면 코드는 그대로) |
| 서버 | `copyVersionToProducts` | 라벨 글자에 실온 · 냉장 · 냉동 중 하나가 들어 있으면 그 코드, 없으면 제품 값을 그대로 둔다 |
| 화면 | 제품등록 | 선택지를 공통코드로, 값은 코드. 견적에서 넘어온 글자는 이름 · 낱말로 코드를 찾아 채운다 |
| 화면 | 제품마스터 창 | 자유 입력 → 고르기(선택 안 함 + 공통코드) |
| 화면 | 제품마스터 · 거래처별 제품조회 목록 | 보관방법 칸은 이름 |

## 하지 않는 것

- 견적(`quotes.storage`)과 견적 화면은 그대로 둔다(요청 범위 밖).
- 라벨 표(`label_requests` · `product_label_versions`)의 보관방법은 인쇄 글자라 그대로 둔다.

## 검증

- DB 시험 실행(다시 적용 · 롤백), 서버 테스트(코드 검사), 화면 테스트, 임시 백엔드로 이름 · 코드 개수 확인, 화면 확인(예시 값)
