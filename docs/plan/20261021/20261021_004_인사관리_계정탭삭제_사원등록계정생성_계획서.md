## 지금 상태 (읽기 전용 확인)

- 사원 2명. 둘 다 username = 이름, 계정 표 줄 있음.
- `employees.username` UNIQUE(`employees_username_key`).
- 사원 등록(`createEmployee`)은 인사정보만 넣는다. 계정은 '로그인계정관리' 탭의 [아이디 만들기]로 따로 만든다.

## 구현 단위

1. 백엔드 `HrServiceImpl.createEmployee`
   - 같은 username(이름) 검사
   - `insertEmployee` 에 username · password_hash(changeme)
   - 계정 표 upsert + DEFAULT_USER(20261021_001 의 `upsertLoginAccount` · `insertDefaultRole`)
2. 매퍼 `EgovHr_SQL.insertEmployee`: username · password_hash 칸 추가
3. 프론트 `HrPage.tsx`: 로그인계정관리 탭 · 단추 · 창 제거
4. 프론트 `HrDialogs.tsx`: 계정 창(`AccountPickDialog` · `AccountDialog`) 제거, 등록 창에 첫 로그인 안내
5. 테스트 · 검증: 단위 테스트, 실제 DB 트랜잭션(등록 → 계정 · 역할 · changeme → ROLLBACK), 화면
