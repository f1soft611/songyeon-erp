# F1-Grid 병합 및 필터 위치 보정 설계

## 목표

- `mergeRows`로 병합된 셀의 마지막 행 경계선을 표시한다.
- 컬럼 필터 메뉴를 선택한 컬럼 헤더의 메뉴 버튼 아래에 안정적으로 표시한다.

## 원인과 해결 방식

병합 셀은 병합 시작 행에서만 렌더링되지만, 기존 하단 테두리는 시작 행이 전체 마지막 행일 때만 표시된다. 병합 시작 셀이 병합 범위의 마지막 행까지 차지하므로, 병합 셀 자체에는 항상 하단 테두리를 적용한다. 병합되지 않은 셀은 기존처럼 전체 마지막 행에서만 하단 테두리를 적용한다.

필터 메뉴는 기존 컬럼 메뉴의 `MenuItem`을 앵커로 사용한다. 이 항목은 필터 메뉴를 열기 전에 부모 메뉴가 닫히면서 DOM에서 제거되므로 MUI가 유효하지 않은 앵커 위치를 계산할 수 있다. 컬럼 메뉴를 열 때 선택한 헤더 메뉴 버튼을 앵커로 보관하고, 필터 메뉴에는 그 버튼을 사용한다.
