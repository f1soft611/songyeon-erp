# 대시보드 사이드바 반응형 접힘 설계

## 목표

중앙 콘텐츠의 가용 폭이 부족해지는 상황에서 모듈 선택 레일은 유지하고 선택된 모듈의 메뉴 패널이 자동으로 접히도록 한다. 사용자는 메뉴 패널을 수동으로 펼치거나 접을 수 있다. 모바일, 태블릿, 데스크톱에서 페이지 전체 가로 스크롤을 방지하며, 넓은 표와 F1-GRID는 해당 영역 내부 스크롤을 사용한다.

## 확정된 동작

- 자동 접힘 기준은 고정 브레이크포인트가 아니라 중앙 콘텐츠의 가용 폭 부족 여부를 기준으로 한다.
- 모듈 선택 레일은 기존 92px 폭을 유지한다.
- 데스크톱의 자동/수동 접힘 상태에서는 메뉴 패널만 숨긴다.
- 모바일에서는 모듈 선택 레일을 유지하고 메뉴 패널을 기본 숨김 상태로 둔다.
- 모바일 메뉴 패널은 앱 바의 메뉴 열기 버튼으로 임시 Drawer 또는 오버레이로 표시한다.
- 수동으로 변경한 상태는 현재 화면 크기에서만 유지한다. 페이지를 다시 열거나 새로고침할 때까지 영구 저장하지 않는다.
- 리사이즈로 모바일과 데스크톱 정책이 바뀌면 해당 정책을 적용한다.
- 모듈 레일의 모듈 아이콘과 라벨은 접힘 상태에서도 접근 가능해야 하며, 메뉴 트리와 사용자 패널만 숨긴다.

## 구조

- `DashboardPage`가 메뉴 패널 상태, 반응형 조건, 토글 핸들러를 소유한다.
- `DashboardSidebar`는 92px 모듈 레일과 메뉴 패널을 조립하고 메뉴 패널의 데스크톱/모바일 표시 상태를 전달한다.
- `DashboardModuleSection`은 모듈 선택 레일을 기존처럼 항상 표시한다.
- `DashboardMenuTree`는 메뉴 패널의 접힘/펼침 상태를 렌더링한다.
- 중앙 콘텐츠 flex item은 `minWidth: 0`을 유지해 자식의 max-content 폭이 문서 폭을 확장하지 않도록 한다.
- F1-GRID 및 넓은 표는 루트의 `overflow-x: auto` 등 기존 내부 스크롤 경계를 유지한다.

## 상태 모델

반응형 상태는 다음 의미를 가진다.

- `isMobile`: 모바일 정책 적용 여부
- `isContentConstrained`: 메뉴 패널을 표시하면 중앙 콘텐츠가 최소 가용 폭을 충족하지 못하는지 여부
- `isMenuPanelCollapsed`: 데스크톱에서 메뉴 패널을 숨길지 여부
- `isMobileMenuOpen`: 모바일 메뉴 패널 오버레이 표시 여부
- `manualOverride`: 현재 화면 크기에서 사용자의 수동 조작을 우선할 수 있는지 여부

콘텐츠 기반 자동 접힘을 감지하기 위해 중앙 콘텐츠 컨테이너의 크기를 관찰한다. 관찰 기준은 92px 모듈 레일과 메뉴 패널을 함께 표시했을 때 중앙 콘텐츠에 필요한 최소 폭이며, 이 값은 기존 화면의 고정 폭과 F1-GRID 내부 스크롤 경계를 고려해 구현한다.

## 접근성 및 UI

- 메뉴 패널 접기/펼치기 버튼은 아이콘과 명확한 `aria-label`, `aria-expanded`를 가진다.
- 모듈 레일의 모듈 버튼에는 기존 모듈명이 accessible name으로 제공된다.
- 모바일 메뉴 패널이 열리면 닫기 동작을 제공하고 콘텐츠를 가리지 않도록 오버레이 또는 Drawer의 기존 동작을 활용한다.
- 선택된 모듈과 메뉴의 시각적 강조는 펼침 상태와 동일하게 유지한다.

## 전체 화면 반응형 점검 범위

공통 앱 셸을 먼저 검증하고, 실제 오버플로우가 발생하는 화면만 국소 수정한다.

- 앱 셸: 모듈 레일, 메뉴 패널, 앱 바, 중앙 콘텐츠의 축소/겹침/문서 폭
- 대시보드와 그룹웨어 화면: 카드, 필터, 버튼 그룹의 줄바꿈
- 설정 화면: 역할/메뉴 관리 필터와 표의 내부 스크롤
- F1-GRID: 컬럼 합계 폭 초과 시 그리드 내부 수평 스크롤

화면 동작이나 기능은 요구 문서에 없는 범위까지 추가하지 않는다.

## 검증

- Vitest: 메뉴 패널 수동 토글, 콘텐츠 제약 상태, 모바일 메뉴 열기/닫기, 기존 모듈/메뉴 선택 회귀를 검증한다.
- 빌드: `npm run build`를 실행한다.
- 브라우저: 375px, 768px, 1280px에서 실제 렌더링을 확인한다.
- 브라우저 측정: `document.documentElement.scrollWidth === window.innerWidth`, 모듈 레일 유지 여부, 메뉴 패널 상태, 중앙 콘텐츠 표시 여부, F1-GRID 내부 수평 스크롤 여부를 확인한다.
- 결과 문서와 스크린샷은 `docs/result/20260828/dashboard-sidebar-responsive/` 아래에 기록한다.

## 범위 제외

- 서버 API, 데이터베이스, 메뉴 데이터 구조 변경
- localStorage를 통한 메뉴 패널 설정 저장
- 관련 없는 페이지의 시각적 리디자인
- F1-GRID 컬럼 폭 정책 자체의 변경
