# F1-GRID Column Management Design

## Goal

F1-GRID 헤더 메뉴에서 컬럼 표시 여부를 빠르게 제어할 수 있도록 한다. 별도의 컬럼 관리 버튼은 제공하지 않는다.

## Scope

- 각 데이터 컬럼 헤더에 메뉴 트리거를 제공한다.
- 메뉴의 `컬럼 목록` 하위 메뉴에서 전체 컬럼을 체크박스로 표시한다.
- 체크된 컬럼은 표시하고, 해제된 컬럼은 숨긴다.
- 마지막으로 표시된 데이터 컬럼은 숨길 수 없다.
- 컬럼의 현재 표시 순서는 유지한다.
- 기존 `headerCheckbox`와 행 선택 체크박스는 컬럼 목록의 대상에서 제외한다.
- 이번 작업에서는 컬럼 폭 변경, 순서 변경, Pin, 정렬, 필터 기능을 추가하지 않는다.

## Component Design

`F1Grid`는 원본 `columns`와 현재 표시 상태를 분리한다. 컬럼 표시 상태는 `hiddenFields`로 관리하며, 현재 표시 컬럼을 계산하는 순수 함수를 통해 Header와 Body에 동일한 컬럼 목록을 전달한다.

`GridHeader`는 MUI `Menu`와 `MenuItem`을 사용해 헤더 메뉴를 렌더링한다. 메뉴 안에서 `컬럼 목록` 항목을 가리키면 `Menu` 기반 서브메뉴가 열리고, 컬럼 체크박스 변경 시 즉시 표시 상태를 갱신한다. 메뉴를 닫아도 상태는 F1Grid 인스턴스에 유지된다.

## Behavior

- 표시 컬럼이 2개 이상이면 모든 표시 컬럼을 숨길 수 있다.
- 표시 컬럼이 1개이면 해당 컬럼의 체크박스를 disabled 처리한다.
- 숨겨진 컬럼은 컬럼 목록에서 해제 상태로 남아 다시 체크할 수 있다.
- 컬럼 목록은 원본 컬럼 정의 순서로 표시한다.
- 편집, 선택, 병합, 복사/붙여넣기의 컬럼 인덱스는 현재 표시 컬럼 기준으로 동작한다.

## Validation

- 순수 함수 테스트: 숨김 컬럼 제외, 원본 순서 유지, 마지막 표시 컬럼 보호
- React 테스트: 헤더 메뉴에서 컬럼 숨김과 재표시, 마지막 컬럼 비활성 상태
- 회귀 검증: 기존 `f1-grid.test.tsx`와 TypeScript/Vite build
