## 1. 메뉴 (DB `20261022_001`)

- `tb_module` DASH: `module_nm` '대시보드' → '홈'
- `tb_menu` DASH 의 `dashboard`: `menu_nm` '대시보드' → '홈'(menu_code · url 그대로라 화면 연결 그대로)
- `tb_module` COMM(메신저·AI): `use_at` 'Y' → 'N'(내 메뉴는 사용 모듈만 내려줌). 메뉴 · 권한 줄은 그대로
- 롤백: 이름 '대시보드', COMM `use_at` 'Y'

## 2. API `/api/v1/dash/memos` (로그인 사용자)

| 동작 | 요청 | 규칙 |
| --- | --- | --- |
| 조회 | `GET ?start=YYYY-MM-DD&end=YYYY-MM-DD` | 공용 전부 + 내 개인. 날짜 · id 순. `resultList` |
| 등록 | `POST { memoDate, title, content, shared }` | 날짜 · 제목 필수. 작성자 = 로그인 사번(`uniqId`) |
| 수정 | `PUT /{id} { title, content }` | 제목 필수. 개인 메모는 작성자 또는 관리자만(아니면 403 문구) |
| 삭제 | `DELETE /{id}` | 수정과 같은 권한 |

- 항목: `id · memoDate · title · content · shared(boolean) · createdBy · createdByName · updatedAt · mine(boolean)`
- 없는 id: "메모를 찾을 수 없습니다"
- 문구(송연 원본 그대로): "날짜는 필수입니다", "제목은 필수입니다", "본인이 작성한 개인메모만 수정할 수 있습니다" / "… 삭제할 수 있습니다"
- 관리자 = `isTenantAdmin`(PLATFORM_ADMIN · TENANT_ADMIN · ADMIN)

## 3. 홈 화면

- 왼쪽 카드 — 달력
  - 위: `‹  2026년 10월  ›`
  - 머리: 일 ~ 토(일 빨강, 토 파랑)
  - 칸: 날짜 숫자, 공휴일 이름(지금 자료), 그날 메모·공지 표(최대 2개 + '외 N')
    - 공지(공용) = 주황, 개인 메모 = 파랑
  - 오늘: 숫자에 진한 원. 고른 날: 옅은 파랑 바탕 + 테두리. 처음 고른 날 = 오늘
  - 달을 바꾸면 그 달 메모를 다시 읽는다
- 오른쪽 카드 — 고른 날
  - 제목 `YYYY-MM-DD`, 단추 [메모·공지 추가]
  - 목록: 구분(공지 / 개인 메모) · 제목 · 내용 · 작성자 · [수정] · [삭제](고칠 수 있는 것만)
  - 없으면 "등록된 메모와 공지가 없어요."
- 창(추가 · 수정): 제목(필수) · 내용 · 공개범위(개인메모 / 공용메모 = 공지, 수정 때는 바꿀 수 없음) · [저장]
  - [삭제]는 확인 후
- '시작하기' 안내는 뺀다.

## 4. 검증

- 백엔드 단위: 필수 검사, 개인 메모 권한(남의 것 403, 관리자 가능), 작성자 = 사번
- 매퍼: 실제 DB 트랜잭션 안에서 등록 · 조회(공용 / 남의 개인 안 보임) · 수정 · 삭제 → ROLLBACK
- 프론트: 서비스 경로 · 본문, 달력 표시 · 고른 날 목록
- 화면: 홈 이름 · 메신저 없음 · 달력 · 오른쪽 목록(쓰기 막음, 메모는 가짜 응답)
