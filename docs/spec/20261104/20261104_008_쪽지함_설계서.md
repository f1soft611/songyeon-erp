## 1. 동작 (S_ERP 와 같음)

- 상단 바 쪽지 아이콘: 안 읽은 쪽지 수, 누르면 쪽지함 `/groupware/messages`(메뉴가 아닌 고정 화면).
- 쪽지함: 전체 · 받은 · 보낸 대화 목록, 대화방(날짜별로 이전 쪽지 더 보기), [새 쪽지](받는 사람 · 제목(선택) · 내용 1~5000자), 답장(Enter 보내기 · Shift+Enter 줄바꿈), 대화방 삭제(나에게만 숨김, 상대가 새로 보내면 다시 보임).
- 쪽지를 받으면 알림 `새 쪽지가 도착했습니다.`(요약 497자, 이모지가 잘리지 않게). 알림을 누르면 그 대화로 간다. 대화를 열면 그 방 쪽지 · 쪽지 알림이 읽음.
- 받는 사람 목록은 사용자 목록 전체(S_ERP 와 같이 나도 보이지만, 나에게 보내면 서버가 거절).

## 2. 송연에 맞춘 점

| 항목 | S_ERP | 송연 |
|---|---|---|
| 사람 | 숫자(`tb_user.user_id`) | 사번 문자열 — 표 · 서버(VO · 서비스) · 화면(타입 · 서비스 · 받는 사람) |
| 대화방 두 사람 순서 | `Math.min/max` | 사번 글자 순서(`compareTo`), 표 제약 a < b 와 같은 기준 |
| SQL | `tb_user` · `tb_login_account` | 그대로(송연 `tb_user.user_id` 가 사번, 계정 3/3 연결) |
| 날짜 | `LocalDateTime` · `LocalDate` | 그대로. log4jdbc 때문에 S_ERP `mapper-config.xml` 날짜 처리기 등록을 함께 옮김(`LocalDateDateTypeHandler` 새로, 처리기 2개 등록) |
| 이벤트 | `s-erp:message-read` 등 | `songyeon-erp:message-read` · `songyeon-erp:realtime` |
| 실시간 | 보냄 · 읽음 · 숨김 때 신호 | 3단계에서 붙임(지금은 화면을 열 때 · 다시 열 때 갱신) |
