## 1. 화면 여백 통일

- 송연 업무 화면의 표 영역 바깥 여백 `p: { xs: 1.5, sm: 1 }`(좁은 화면 12px)을 S_ERP 와 같은 `p: 1`(8px)로 바꿨다. 47개 화면(기준정보 · 영업 · 생산 · 물류 · 판매 · 구매 · 품질 · 상품개발 · 인사회계).
- S_ERP 에서 그대로 가져온 `settings/system/warehouses/components/WarehouseManagementPanel.tsx` 는 S_ERP 도 같은 값이라 그대로 뒀다.
- 결과: 375px 에서도 결과 안내 위 · 아래 8px(20261104_004 의 남은 차이 해소).

## 2. 최근 사용 메뉴 PC 유지 (S_ERP 와 같음)

- 저장 위치: 탭 세션(sessionStorage) → 이 PC 브라우저(localStorage), 키 `songyeon-erp:recent-menu-history`(송연 키 그대로).
- 읽기: localStorage 먼저, 없거나 깨졌으면 예전 sessionStorage 기록. 항목마다 필수 칸 · 방문 시각을 확인하고 맞는 것만 최대 5건.
- 쓰기: localStorage 에 쓰고 sessionStorage 의 예전 기록은 지운다(옮기기). 저장소 오류가 나도 메뉴 이동은 그대로.
- 로그아웃해도 지우지 않는다(예전에는 지웠다). 공통코드 조회 상태는 지금처럼 로그아웃 때 지운다.
- 최신순 · 중복 없음 · 5건 · 클릭 이동 · 시간 표시는 그대로.
- 변경: `pages/dashboard/DashboardPage.tsx` 의 `readRecentMenus` · `writeRecentMenus` · 상태 · `handleLogout`(S_ERP 최신본과 같은 코드).
