## 1. 동작 (S_ERP 와 같음)

- 왼쪽 메뉴 트리: 읽기 권한이 있는 마지막 메뉴 옆에 별표. 빈 별을 누르면 바로 즐겨찾기 맨 위(루트)에 등록하고 편집창(이름 · URL · 폴더)을 연다. 채운 별을 누르면 편집창. 메뉴 화면으로 이동하지는 않는다.
- 편집창: 이름 바꾸기(공백 제외 1~100자), 폴더 고르기(즐겨찾기 루트 또는 폴더), 완료 · 제거 · 더보기(즐겨찾기 모듈 열기). 저장에 실패하면 창과 입력값을 그대로 둔다.
- 즐겨찾기가 1건 이상이면 모듈 줄 아래에 '즐겨찾기' 버튼. 누르면 즐겨찾기 트리(폴더 · 바로가기)를 보여 주고, 다른 모듈을 누르면 원래 메뉴 트리로 돌아간다.
- 즐겨찾기 트리: '새 폴더'(1~40자), 바로가기 · 폴더 작업 메뉴(루트로 이동 · 폴더로 이동 · 즐겨찾기 해제, 폴더 이름 바꾸기 · 삭제). 메뉴가 들어 있는 폴더는 지울 수 없다. 폴더와 같은 이름의 메뉴는 아이콘 · 이름표로 구분한다(20261103_004).
- 메뉴에서 오른쪽 클릭(또는 Shift+F10 · 메뉴 키)으로도 같은 작업 메뉴.
- 권한이 없어진 메뉴의 즐겨찾기는 목록에 보이지 않는다. 즐겨찾기를 못 불러오면 아래에 오류 알림과 '다시 시도'.

## 2. 송연에 맞춘 점

- 사람 칸: S_ERP 는 로그인 사람 번호(`uniqId`)를 1 이상의 숫자로 바꿔 쓴다. 송연은 사번(`00123` 처럼 0 으로 시작할 수 있음)을 문자열 그대로 쓰고 빈 값만 막는다(20261103_003 사번 통일). 표의 `user_id` 도 `varchar(20) → employees.id`.
- 모듈 줄 로고: 송연은 'SONGYEON' 글자이고 누르는 링크가 없다(S_ERP 의 종합현황 링크는 즐겨찾기와 다른 변경이라 넣지 않음). 모듈을 누른 뒤 포커스를 빼는 것(`blur`)은 즐겨찾기 변경이라 S_ERP 와 같이 넣었다.
- `DashboardPage`: S_ERP 는 메뉴 불러오기 상태를 `useInitialLoadState` 로 다루지만 송연은 기존 방식(`menusError`)이라, 즐겨찾기 부분(불러오기 · 새로고침 · 오류 알림 · 즐겨찾기 모듈 선택)만 같은 자리에 넣었다.
