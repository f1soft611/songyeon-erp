## 1. 방식

- 송연 파일이 S_ERP 예전 버전 그대로인 것(송연 수정 없음)은 S_ERP 최신을 그대로 복사했다.
- 송연 수정이 섞인 것은 3방향 병합으로 맞췄다: 기준 = 송연과 가장 비슷한 S_ERP 예전 버전, 한쪽 = 송연, 다른 쪽 = S_ERP 최신. 충돌만 손으로 정했다.
- 송연 로그인 화면(`LoginPage` · `LoginForm` · `useLoginForm`)은 송연이 따로 디자인한 화면이라 그대로 두었다.

## 3. 테스트

- S_ERP 최신 테스트로 맞춤: 공통코드(화면 · 서비스 · 도움말 창), 모듈관리, 결재양식(병합), 역할관리(병합), 새로 `app-loading-spinner` · `master-picker` · `login-form-field` · `auth-layout`. 송연 값으로 바꾼 것: 사번 문자열(`'12'`, `'00000110'`), 검색 유지 키 `songyeon-erp:page:*`.
- F1-Grid: S_ERP 테스트 2건(빈 숫자 셀 · 0 구분)을 먼저 넣어 실패를 확인한 뒤 본체를 복사해 통과.
- 저장 키: 자료실 · 문서현황 테스트를 송연 키로 먼저 바꿔 실패(5건) 확인 → 코드 변경 뒤 통과.
- 비교 기준: S_ERP 최신 복사본(임시 폴더)을 같은 환경에서 돌린 결과. 공통코드 · 결재양식 · 역할관리 3파일은 S_ERP 최신에서도 19건이 이 환경에서 실패하며, 송연은 사번 기대값을 맞춘 뒤 같은 실패만 남는다.

## 4. 검증 결과

- 서버: 본문 이미지 저장 테스트(`EmbeddedImageStorageServiceImplTest`)도 S_ERP 최신으로 맞춤(송연 수정 없던 파일). 전체 870건 중 기존 실패 `MinioStorageConfigTest` 1건(설정 파일 없음)만.
- 화면 전체: S_ERP 최신 복사본 실패 218건, 송연 200건. 송연에만 있는 실패 3건(자료실 상세검색 초기화, 공통코드 저장 잠금, F1-Grid 스크롤)은 모두 단독 실행에서 통과하며, 전체 실행 때 3초 가까이 걸리는 테스트가 시간 초과한 것이다.
- 화면 빌드: 이번 변경 파일은 통과. 구매 입고 화면(`ReceivingHistoryGrid` · `ReceivingReturnGrid` · `SubstitutionGrid`)의 쓰지 않는 import 오류는 진행 중인 다른 작업 파일이라 건드리지 않았다.
- 로그인 화면: 1280px 밝은 화면 · 375px 어두운 화면 확인, 화면 오류 0, 가로 넘침 없음, 모양 변화 없음.
