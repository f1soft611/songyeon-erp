## 1. 동작

- 마지막으로 조회한 조건을 브라우저 탭 세션(sessionStorage)에 둔다. 다른 화면에 갔다 돌아오면 그 조건으로 다시 조회하고, 검색줄 · 날짜 칸 · 상세 조건 칩도 그대로 보인다(S_ERP `usePageSessionState` 방식).
- 그리드는 같은 조건으로 다시 부른다(행을 보관하지 않는다). 저장하지 않은 편집은 지금처럼 남지 않는다.
- 탭을 닫으면 사라진다. 처음 여는 화면은 지금 기본값 그대로(오늘 · 이번 달 등).
- [조회]를 눌러야 부르던 화면(생산현황 · 출하현황 · 라벨출력 · 생산가능확인)은 조회한 적이 있을 때만 돌아오면 바로 부른다.
- 저장 키는 `songyeon-erp:page:<화면>`, 버전 1. 저장 값 모양이 처음 조건과 다르면(예전 값 · 깨진 값) 버리고 기본값으로 연다.

## 2. 공통 도우미 `frontend/src/shared/utils/searchSession.ts`

| 함수 | 내용 |
|---|---|
| `readSearchSession(page, fallback, sample?)` | 저장 값이 있고 모양이 맞으면 그 값, 아니면 `fallback`. `sample` 의 빈 객체 자리는 상세 조회 값(`isPageSearchValues`), 목록 자리는 목록이어야 한다 |
| `saveSearchSession(page, value)` | 저장 |
| `clientProductDetailValues(filter)` | 상세 조회 거래처 · 품목 조건 → 칩 값(빈 조건은 뺀다) |

## 3. 화면별 저장 조건

| 화면 | 키 | 저장하는 조건 | 저장 시점 |
|---|---|---|---|
| 수주등록 | `sales-order-register` | 수주일 · 상세(거래처 · 품목) | 조회할 때. 생산확정에서 넘어온 경우 상세 조건은 비운다 |
| 견적 | `sales-quote` | 검색어 | 바뀔 때(화면에서 거름) |
| 생산가능확인 | `sales-prod-check` | 생산일자 · 만들 것 줄(제품 · 수량) | [확인] 성공 때. 돌아오면 다시 확인 |
| 단가관리 | `sales-pricing` | 검색어 · 상세(거래처 · 차액금) | 바뀔 때 |
| 출하등록 | `sales-shipment-register` | 출하일 · 상세 | 조회할 때 |
| 생산확정 · 생산입고 | `pd-prod-confirm` · `pd-prod-actual` | 생산일자 · 상세 | 조회할 때 |
| 라벨출력 | `pd-label-print` | 생산확정일 | 조회할 때 |
| 생산현황 · 출하현황 | `pd-prod-status` · `lg-ship-status` | 기간 · 상세 | 조회할 때 |
| 출하확정 | `lg-ship-confirm` | 출고일 · 상세 | 조회할 때 |
| 제품재고관리 | `lg-product-stock` | 검색어 · 상세(거래처 · 정렬) | 조회할 때 |
| 판매등록 · 판매현황 · 토탈집계 | `sl-sales-register` · `sl-sales-status` · `sl-sales-total` | 거래처 검색어 · 상세 조회 값 | [조회] 적용 때 |
| 발주등록 | `pu-order-register` | 상세 발주일 · 거래처 | 조회할 때 |
| 발주현황 · 입고현황 · 서류등록 | `pu-order-status` · `pu-receiving-status` · `pu-receiving-doc` | 조회 조건 전체 | 조회할 때 |
| 입고등록 · 반품등록 | `pu-receiving-register` · `pu-return-register` | 기간 · 거래처 | 조회할 때(등록 뒤 옮긴 날짜 포함) |
| 재료 치환등록 | `pu-substitution` | 생산일자 | 조회할 때 |
| 수불대장 | `pu-stock-ledger` | 조회 기간 · 탭 · 검색어 · 보기 | 기간은 조회할 때, 나머지는 바뀔 때 |
| 재고현황 | `pu-stock-status` | 조회 기준일 · 탭 · 검색어 · 재고 있는 것만 | 기준일은 조회할 때, 나머지는 바뀔 때 |

- 검색줄에 치기만 하고 조회하지 않은 글자는 서버 조회 화면에서는 남기지 않는다(S_ERP 와 같음). 화면에서 바로 거르는 검색어는 남긴다.

## 4. 검증 기준

- 화면마다: 조건을 바꿔 조회 → 다른 화면 → 돌아오면 칸 값 · 칩이 같고, 떠나기 전 마지막 조회 요청(주소 + 조건)이 다시 나간다. 화면 오류 0, 저장 · 삭제 요청 0.
- 대조: 돌아오기 전에 세션을 지우면 위 비교가 달라져야 한다.
