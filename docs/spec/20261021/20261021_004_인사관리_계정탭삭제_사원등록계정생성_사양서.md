## 1. 사원 등록 (`POST /api/v1/ha/hr/employees`, 응답 그대로 `{ id }`)

1. 이름 필수(지금과 같음)
2. 같은 username(= 이름)인 사원이 있으면 막는다: "같은 이름의 사원이 이미 있어요. 이름 뒤에 구분을 붙여 주세요(예: 김민수B)"
3. `employees` 에 넣는 값: 지금 칸 + `username` = 이름, `password_hash` = Werkzeug(`changeme`)
4. 계정 표: `upsertLoginAccount`(login_code = 사번, 비밀번호 = employees 와 같은 해시) → `insertDefaultRole`(DEFAULT_USER)
5. 한 트랜잭션(`*Impl` 공통). 중간에 실패하면 사원도 들어가지 않는다.

- 사원 수정(`updateEmployee`)은 지금과 같다(username 은 바꾸지 않음).
