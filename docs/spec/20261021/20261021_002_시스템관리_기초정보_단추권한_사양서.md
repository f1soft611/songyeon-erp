# 20261021_002 시스템 관리 · 기초정보 화면 단추를 메뉴 권한에 맞추기 사양서

## 1. 권한 규칙 (메뉴관리 기본기능 4칸)

| 기본기능 | 메뉴 권한 | 보이거나 되는 것 |
| --- | --- | --- |
| 읽기 | READ | [조회], 보기 전용 단추(상세보기 · 변경로그 · 역전개 · 해제 · 필터) |
| 쓰기 | CREATE 또는 UPDATE | [추가] · [등록] · [저장] · [수정] · [일괄적용] · [단종] 류, 오른쪽 클릭 [행 추가] · [루트 추가], 셀 편집 · 체크 칸, 창의 [저장] · [등록] |
| 삭제 | DELETE | [삭제], 오른쪽 클릭 [행 삭제], 창의 [삭제] |
| 엑셀 | EXCEL | [엑셀 다운로드](제목줄 · 화면 안), [엑셀 양식 내려받기], 그리드 메뉴 엑셀 내보내기. [엑셀 올리기]는 엑셀 + 쓰기 |

- 단추는 권한이 없으면 숨긴다(지금 제목줄 방식과 같음). 셀 편집은 막는다(`editable: false`).
- 권한이 모두 있으면 지금 화면과 같다.

## 2. 화면별

| 화면 | 바꾸는 것 |
| --- | --- |
| 공통코드 관리 | 오른쪽 클릭 [루트 추가] · [행 추가] = 쓰기, [행 삭제] = 삭제, 셀 편집 = 쓰기(두 그리드) |
| 포장유형 · 창고등록 | 오른쪽 클릭 [행 추가] = 쓰기, [행 삭제] = 삭제, 셀 편집 = 쓰기, 제목줄 [엑셀 다운로드] = 엑셀 |
| 제품마스터 | 줄 [수정] · 쓰기 단추 = 쓰기 |
| 거래처마스터 | 제목줄 [엑셀 다운로드] = 엑셀, [엑셀 양식 내려받기] = 엑셀, [엑셀 올리기] = 엑셀 + 쓰기, 창 [저장] · [등록] = 쓰기, 창 [삭제] = 삭제, 쓰기가 없으면 창의 칸은 읽기 전용 |
| 거래처별 제품조회 | [상세보기] 창(제품BOM 창)의 '수정' 탭 = 쓰기 |
| 원재료마스터 | 줄 [수정] · [일괄적용] = 쓰기, [엑셀 다운로드] = 엑셀 |
| 부자재마스터 | 줄 [수정] = 쓰기, [엑셀 다운로드] = 엑셀 |
| 모듈관리 | 오른쪽 클릭 [행 추가] = 쓰기, [행 삭제] = 삭제, 셀 편집 = 쓰기 |
| 권한관리 | 셀 편집 · 사용자 매핑 체크 = 쓰기, 역할 그리드 오른쪽 클릭 [행 추가] = 쓰기 · [행 삭제] = 삭제 |
| 메뉴관리 | 셀 편집 · 사용 여부 · 기본기능 체크 = 쓰기, 오른쪽 클릭 [루트 추가] · [행 추가] = 쓰기 · [행 삭제] = 삭제 |

- 줄 단추 칸은 그대로 두고 쓰기 단추만 숨긴다(부자재 [수정] 칸은 비어 보인다). 칸을 빼면 저장된 칸 순서가 흔들리기 때문이다.
- 제품BOM 창 · 원재료 창: 쓰기가 없으면 '수정' · '단가수정' 탭을 숨긴다(거래처별 제품조회 [상세보기]도 같은 창이라 함께 적용).
- 정확한 단추 목록은 구현 때 코드에서 확인해 결과 문서에 적는다.

## 3. 검증

- 도우미 단위 테스트: `screenPermissionsOf`, `readOnlyColumns`
- 화면 테스트: 권한 없음 / 모두 있음 렌더(단추 보임 여부)
- 화면 확인: 읽기 · 엑셀만 준 시험 토큰으로 화면을 열어 단추 · 편집이 막히는지, 시스템 관리자 토큰으로 지금과 같은지. GET 만 실제 서버, 쓰기 막음
