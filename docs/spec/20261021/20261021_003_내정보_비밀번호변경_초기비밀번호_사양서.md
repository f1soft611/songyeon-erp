## 2. 인사관리 아이디 만들기 — 첫 비밀번호

- 서버 `saveAccount`: 그 사원에게 아이디가 없던 경우(처음 만듦) 비밀번호는 보낸 값과 상관없이 `changeme`(Werkzeug 해시)
  - 옛 검사 "처음 만들 때는 비밀번호도 정해주세요"는 없앤다.
  - 이미 아이디가 있는 사원은 지금과 같다(적으면 바꾸고, 비우면 그대로).
  - `changeme` 는 8자라 내 정보 · 보안 설정의 8자 규칙에도 맞는다.
- 창(`AccountDialog`)
  - 처음 만들 때: 비밀번호 칸 대신 "처음 비밀번호는 changeme 입니다. 로그인한 뒤 내 정보에서 바꾸세요." 안내
  - 이미 있을 때: 지금처럼 '비밀번호 — 바꿀 때만 적어요'
- 로그인은 사번 + changeme
