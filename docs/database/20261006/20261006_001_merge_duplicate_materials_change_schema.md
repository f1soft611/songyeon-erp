## 이유

- 같은 이름·규격의 원재료가 두 번 등록돼 있었다(사용자 요청으로 정리).
  - MSG(L-글루탐산나트륨) 25kg: 000004(2,650원, 9/21 등록) · 000014(1,270원, 10/6 등록)
  - 흑후추분말 20kg: 000005(7,500원) · 000015(7,500원, 10/6 등록)
- 먼저 등록되고 재고·생산 투입 기록이 붙은 000004·000005 를 남긴다. MSG 단가는 2,650원(사용자 선택).

## 적용 전 확인(읽기 전용)

- 000014·000015 를 쓰는 곳: 제품 배합비 김치찌개분말(000003) 각 1줄, 단가 변경 이력 각 1줄. 재고 0, 입고·생산 투입·납품업체·레시피·제품 부자재 칸 참조 없음.
- 김치찌개분말은 000004·000005 를 따로 쓰지 않아 합쳐도 같은 원재료가 두 줄이 되지 않음.

## 영향 범위

- 김치찌개분말(000003) 배합비: MSG 줄 000014 → 000004, 단가 1,270 → 2,650원, 적용단가 64.135 → 133.825원. 흑후추분말 줄 000015 → 000005(단가 같음).
- 김치찌개분말 단가표: 원재료비·제품단가가 69.69원 오름(1,725.445 → 1,795.135).
- 국물두루치기분말 등 000004·000005 를 원래 쓰던 제품은 바뀌지 않음.
- 제품BOM 변경로그(product_bom_log)의 지난 기록 안 원재료코드는 그대로 둔다(그때의 기록).
