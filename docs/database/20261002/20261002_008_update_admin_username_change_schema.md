| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-02 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 데이터 수정 (스키마 변경 없음) |
| 대상 표 | employees (id = 1 의 username: '관리자' → '0000') |
| 적용 | 2026-10-02 적용 후 같은 날 롤백(20261002_008_rollback.sql) — 사용자 요청을 잘못 이해한 변경. 지금 username = '관리자' |
| 롤백 | `20261002_008_rollback.sql` ('0000' → '관리자') |

## 이유

- 사용자 요청: 로그인할 때 '관리자' 대신 '0000' 을 입력해 로그인한다.

## 영향 범위

- 로그인 아이디만 바뀐다. 이름(`employees.name`)·비밀번호는 그대로.
- **송연 원본 프로그램도 같은 `employees` 로 로그인하므로 원본에서도 '0000' 으로 로그인해야 한다.**
- '관리자' 라는 값이 있는 다른 칸(`tb_tenant.admin_name`, `product_stock_movement.created_by_name`)은 아이디가 아니라 사람 이름이라 바꾸지 않는다.
- 바꾸기 전 '관리자' 로 로그인해 둔 화면은 다시 로그인해야 내 정보 관리 등이 맞게 동작한다.
