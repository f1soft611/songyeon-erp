# 20261002_002 송연 메뉴 구성 시드 변경 이력

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-02 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 데이터 시드 (스키마 변경 없음) |
| 선행 | 20261002_001 (내부 테넌트·기능 권한·환경설정 메뉴) |
| 적용 | 2026-10-02 적용 완료 (트랜잭션 시험 실행 후 적용) |
| 롤백 | `20261002_002_rollback.sql` |

## 내용

송연 메뉴 구성(송연 변환본 `frontend/src/shared/config/navigation.ts` 기준, 기존 pricing.html 의 분류·순서·이름)을 S_ERP 메뉴 표에 등록한다. 메뉴관리 화면에서 그대로 보고 고칠 수 있다.

| 표 | 넣은 행 |
|---|---|
| tb_module | 대시보드(DASH) · 메신저·AI(COMM) · 영업관리(SA) · 공통관리(CM) · 생산관리(PD) · 물류관리(LG) · 판매관리(SL) · 구매관리(PU) · 품질관리(QM) · 상품개발(RD) · 인사·회계(HA) — 11개, 정렬 1~11 |
| tb_menu | 송연 메뉴 42개. `menu_code` = 송연 메뉴 id(기존 화면 ID, 예: product), `menu_url` = `/<분류>/<메뉴 id>`. 전환된 화면은 설명에 송연 화면코드(SA0001 등) |
| tb_menu_permission | 42개 메뉴 × 조회·등록·수정·삭제·엑셀 (210) |

적용 뒤 전체: 모듈 12(환경설정 포함), 메뉴 49, 메뉴 기능 240.

## 권한

- 송연에는 역할·권한 개념이 없으므로(2026-10-02 결정) 로그인한 모든 사용자가 모든 메뉴와 기능을 쓴다.
- 로그인 토큰에 역할이 없으면 S_ERP 메뉴 서비스가 메뉴별 기능 전체(`tb_menu_permission`)를 준다. 그래서 메뉴마다 다섯 기능을 모두 등록했다.
- `tb_role_menu_permission`은 쓰지 않는다(권한관리 화면은 S_ERP 그대로 남겨둠).

## 화면 연결

- 아직 송연 업무 화면을 이 프로젝트로 옮기지 않았으므로 메뉴를 누르면 "준비 중" 화면이 나온다.
- 화면을 옮길 때 `DashboardContent.tsx`에 모듈 id(`sa` 등) + 메뉴 id(`product` 등)로 연결한다.
