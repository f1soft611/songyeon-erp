# 20261002_004 환경설정 창고관리·고객정보 메뉴 제거 변경 이력

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-02 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 데이터 삭제 (스키마 변경 없음) |
| 대상 표 | tb_menu (ST_WAREHOUSE, ST_CUSTOMER) → CASCADE: tb_menu_permission(10행), tb_role_menu_permission(8행) |
| 적용 | 2026-10-02 적용 완료 (트랜잭션 시험 실행 후 적용) |
| 롤백 | `20261002_004_rollback.sql` (20261002_001 과 같은 값으로 다시 넣음) |

## 이유

- 사용자 요청으로 환경설정 > 시스템 관리 의 창고관리·고객정보 메뉴를 없앤다.
- 송연 창고는 공통관리 > 기초정보 > 창고등록(송연 `warehouses` 표)에서 관리한다. S_ERP 창고관리(`tb_warehouse`)는 쓰지 않는다.
- 고객정보는 S_ERP 에도 화면이 없던 메뉴였다.

## 영향 범위

- 환경설정 > 시스템 관리 에 남는 메뉴: 모듈관리 · 권한관리 · 메뉴관리 (F1 Grid 테스트는 원래 사용안함).
- 화면 코드(S_ERP 창고관리 페이지·API)는 그대로 둔다. 메뉴가 없어 화면에서 들어갈 수 없다.
