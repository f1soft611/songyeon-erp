## 내용

- 요청: "메뉴관리에 이것도 똑같이 적용해줘"(S_ERP 메뉴관리 · 그룹웨어 · 플랫폼 관리자 화면)
- S_ERP DB 의 GROUPWARE 메뉴 설정을 읽어 같은 값으로 맞췄다.
  - 게시판(`GW_BOARD`) 메뉴 추가: 커뮤니티 아래, `/groupware/community/board`, 아이콘 article, 정렬 22, 사용안함, 설명 '일반 게시판'
  - 게시판 종류 `BOARD`(게시판, board, 읽기 ALL · 쓰기 MEMBER, 파일 N, 순서 2) 추가
  - 기능 권한(`tb_menu_permission`): S_ERP 처럼 게시판 권한만 둔다(커뮤니티 BOARD_VIEW, 공지사항 BOARD_VIEW · WRITE · DELETE, 게시판 BOARD_VIEW · WRITE, 자료실 BOARD_VIEW · UPLOAD). 003 에서 넣은 READ ~ EXCEL 은 뺐다.
  - 역할 권한: 일반 사용자 · 플랫폼 관리자 · 커뮤니티 관리자를 S_ERP 와 같은 값으로 넣었다(예: 일반 사용자는 종합현황 · 공지사항 · 자료실 읽기, 문서작성 · 문서현황 읽기 · 쓰기).
- 시스템 관리자(`ADMIN`)는 S_ERP 에 그룹웨어 권한이 없다. 하지만 송연 관리자 계정이 이 역할이라 003 값(모두 허용)을 그대로 뒀다.
- 확인: 적용한 뒤 S_ERP DB 와 세 가지를 비교했고 모두 같았다.
  - 메뉴(코드 · 부모 · 이름 · 주소 · 아이콘 · 정렬 · 사용 · 설명 · 기능 권한)
  - ADMIN 을 뺀 역할 권한
  - 게시판 종류

## 영향 범위

- 일반 사용자 · 플랫폼 관리자 · 커뮤니티 관리자 역할 계정에도 그룹웨어 메뉴가 보인다(역할 권한대로).
- 게시판 메뉴는 사용안함이라 왼쪽 메뉴에 보이지 않는다.
