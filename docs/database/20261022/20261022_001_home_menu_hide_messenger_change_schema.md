|---|---|
| 날짜 | 2026-10-22 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 데이터 변경 (스키마 변경 없음) |

## 내용

- 요청: "지금 대시보드를 이렇게 바꿀 수 있나? 홈으로. 메신저AI는 빼고"
- DASH 모듈 · `dashboard` 메뉴 이름: '대시보드' → '홈'
  - `menu_code` · `menu_url` 은 그대로라 화면(`DashboardHomePage`) 연결도 그대로다.
- COMM(메신저·AI) 모듈: `use_at` 'Y' → 'N'
  - 내 메뉴는 사용 중인 모듈만 내려줘서 왼쪽에서 사라진다.
  - 메뉴(메신저 · AI 분석) · 권한 줄은 지우지 않았다. 롤백하면 그대로 돌아온다.

## 영향 범위

- 모든 사용자의 왼쪽 메뉴
- 메신저 · AI 분석 화면은 메뉴가 없어 열 수 없다(코드는 그대로).
- 홈 화면의 메모·공지는 이미 있던 `dashboard_memos` 표를 쓴다(표 변경 없음, 새 API `/api/v1/dash/memos`).
