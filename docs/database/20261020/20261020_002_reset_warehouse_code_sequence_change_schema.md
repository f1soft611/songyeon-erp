# 20261020_002 창고 자동 코드 WH-001 부터 변경 이력

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-20 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 데이터 변경 (스키마 변경 없음) |
| 대상 표 | `tb_warehouse.warehouse_cd` (1줄), `tb_id_sequence` (키 `WAREHOUSE_CODE` · `F001` · `P001`) |
| 적용 | 2026-10-20 적용 완료 (트랜잭션 시험 실행 후 적용) |
| 롤백 | `20261020_002_rollback.sql` (WH-001 → WH-004, 번호표 4) |

## 내용

- 요청: "데이터 지우고 등록했는데 WH-004 부터 저장돼. 001 부터 시작하게 해줘"
- 원인
  - 번호표 마지막 값이 3이었다. 지우기 전 옛 자동 코드 `WH001` ~ `WH003` 이 쓴 값이다.
  - 그래서 새 자동 코드가 `WH-004` 로 나왔다.
- 바꾼 것
  - 자동으로 받은 `WH-004` 1줄 → `WH-001`
    - 가리키는 곳이 없다: 상위창고 0건, 창고 위치(`tb_warehouse_location`) 0건.
  - 번호표 4 → 1. 다음 자동 코드는 `WH-002` 다(이미 있는 코드는 건너뛴다).
- 나머지 창고 코드(`WH-WEIGH` · `WH-MATERIAL` · `WH-PRODUCT`)는 직접 적은 코드라 그대로다.

## 확인

- 한 트랜잭션 안에서 아래를 했다.
  1. 적용(코드 WH-001, 번호표 1) → 다시 적용(같음)
  2. 롤백 스크립트(원래대로)
  3. ROLLBACK
- ROLLBACK 뒤 그대로였다. 그 뒤 적용했다.
