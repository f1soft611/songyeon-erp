## 내용

- 요청: 거래처마스터에 등록자~수정일시 칸을 더했는데 오류가 났다(제품마스터와 같은 원인). 사용자 결정: 등록일시는 기존 `created_at` 을 쓴다.
- `clients` 에 3칸을 더했다(포장유형 · 제품과 같은 형식).
  - `reg_user_id VARCHAR(20)`
  - `upd_user_id VARCHAR(20)`
  - `upd_dt TIMESTAMP`
- 등록일시는 있는 `created_at`(글자, 19건 모두 `YYYY-MM-DDTHH:MM:SS`)을 화면에서 `YYYY-MM-DD HH:MM:SS` 로 보여 준다.
- 값을 넣는 곳(`PartnerMaster_SQL_postgresql.xml`, 사번 = 로그인 사원)
  - 등록자: [거래처 등록] · 엑셀 올리기의 새 거래처
  - 수정자 · 수정일시: 거래처 창 저장, 엑셀로 있는 거래처 덮어쓰기, 사용여부 저장
- 이미 있는 거래처의 등록자 · 수정자는 비워 두었다.

## 영향 범위

- 거래처마스터 목록 · 엑셀 양식 행이 등록자 · 수정자 이름(사원 이름, 없으면 사번)과 일시를 돌려준다.
- 컬럼은 모두 비어도 된다. 그래서 이 칸을 쓰지 않는 다른 쿼리는 그대로 동작한다.
