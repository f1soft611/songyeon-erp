## 내용

- 요청: "materials테이블도 등록자~수정일시 컬럼 추가해줘 포장유형처럼"
- 포장유형(`tb_box_type`) · 제품(`products`)과 같은 이름 · 형식으로 4칸을 더했다.
  - `reg_user_id VARCHAR(20)`
  - `reg_dt TIMESTAMP`
  - `upd_user_id VARCHAR(20)`
  - `upd_dt TIMESTAMP`
- 값을 넣는 곳
  - 등록자 · 등록일시: 원재료 · 부자재 신규 등록(`MaterialMaster_SQL_postgresql.xml` `insertMaterial`, 사번 = 로그인 사원)
  - 수정자 · 수정일시: 원재료 · 부자재 창의 기본정보 저장 뒤, 바로 반영한 단가 저장 뒤(`updateMaterialAudit`)
  - 수정으로 치지 않는 것
    - 재고 수량 변동(입고 · 재고조정 · 생산 차감)
    - 창고 이름 따라가기
    - 앞날로 예약한 단가와 그날 자동 반영
- 이미 있는 원재료 · 부자재는 비워 두었다(누가 언제 만들었는지 알 수 없다).

## 영향 범위

- 원재료마스터 · 부자재마스터 목록이 등록자 · 수정자 이름(사원 이름, 없으면 사번)과 일시를 돌려준다.
- 컬럼은 모두 비어도 된다. 그래서 이 칸을 쓰지 않는 다른 쿼리는 그대로 동작한다.
- 롤백하면 쌓인 값도 사라진다. 서버 코드도 20261023_008 이전으로 함께 돌려야 한다.
