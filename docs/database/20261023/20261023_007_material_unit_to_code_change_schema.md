|---|---|
| 날짜 | 2026-10-23 |
| 대상 DB | songyeon (PostgreSQL) |
| 유형 | 데이터 변경 + 백업 표 생성 |
| 대상 표 | `materials`(`unit`), `bak_20261023_007_material_unit`(롤백용, 새로 만듦) |
| 참조 | 공통코드 `UNIT`(SONGYEON, 사용자가 만든 것): 001 KG · 002 EA · 003 BOX · 004 M |
| 적용 | 2026-10-23 적용 완료 (트랜잭션 시험 실행: 다시 적용해도 같음, 롤백하면 처음과 같음 확인 후 적용) |
| 롤백 | `20261023_007_rollback.sql`(남긴 원래 글자로 되돌리고 백업 표를 지운다) |

## 내용

- 요청: "원재료랑 부자재 단위도 공통코드 UNIT 로 봐야될듯"(거래처 · 부자재 분류와 같게 저장은 코드, 화면은 이름)
- `materials.unit` 을 대소문자 · 앞뒤 공백 없이 견줘 코드로 바꿨다.
  - `kg` 48건 · `KG` 1건 → 001
  - `EA` 1건 → 002
  - 빈 값 3건은 그대로다.
- 롤백이 원래 글자(대소문자 그대로)로 돌릴 수 있게, 바꾸기 전 값을 `bak_20261023_007_material_unit`(code, unit) 에 남겼다.
  - 처음 시험 실행 때 'KG' 가 'kg' 로 돌아가는 차이를 보고 더했다.
- 스크립트는 먼저 공통코드에 001 ~ 004 가 다 있는지 보고, 없으면 멈춘다.

## 영향 범위

- 단위를 읽는 쿼리는 모두 이름(`unit_nm` / `unitNm`)을 함께 준다.
  - 원재료 · 부자재마스터
  - 수불대장
  - 재고조정 창고 이동 조회(화면 표시 단위는 이름, 비었으면 예전처럼 kg)
- 원재료 · 부자재 저장은 공통코드 사용 중 코드만 받는다(비우면 비움).
- 화면 표시가 `kg` 에서 공통코드 이름 `KG` 로 바뀐다.
- 이 DB 를 쓰는 다른 프로그램(예전 송연 파이썬)이 `unit` 글자를 직접 보면 코드로 보인다.
