## 내용

- 요청: "materials 테이블에 supplier컬럼 있는데 이걸 client_code로 바꾸고 지금 id 로 저장되는걸 000001이렇게 저장되게 할 수 있나?"
- 사용자 결정: 업체 여러 곳 유지, DB 는 Claude 가 스크립트로
- 바뀐 모양
  - 칸 이름 `supplier` → `client_code`(6번째 자리, text 그대로)
  - 값: 거래처 id 배열 `[3,5]` → 거래처코드 배열 `["000003","000005"]`(고른 순서 그대로). 한 곳이면 `["000003"]`
- 결과(개수만)
  - 56건 중 22건이 id 배열이었고 모두 코드 배열이 됐다. 22건 모두 거래처마스터와 이어진다.
  - 빈 값 34건은 그대로다.
- id 가 거래처마스터에 없거나 거래처코드가 비어 있으면 멈춘다(적용 때 0건).
- 바꾸기 전 값 22건은 `bak_20261023_015_material_supplier` 에 남겼다.

## 영향 범위

- 원재료마스터 · 부자재마스터 목록과 원재료 창 저장은 거래처코드로 주고받는다(`supplierCodes`, `suppliers[].clientCode`).
- 납품업체 고르기 목록에 `clientCode` 가 더해졌다(거래처코드 없는 거래처는 빠진다).
- 수불대장은 거래처코드 배열을 풀어 거래처 이름으로 보여 준다.
- 롤백하면 `supplier`(거래처 id 배열)로 돌아간다. 적용 뒤 새로 고친 원재료는 코드를 id 로 바꿔 넣는다. 서버 · 화면 코드도 함께 돌려야 한다.
